## 3. 故障排查速查(P4b 增量)

| 现象 | 先查 |
|---|---|
| 主题切换不记忆 | localStorage 可用性(隐私窗/被禁,saveTheme 静默);查 `mtdss.theme` 值拼写 |
| 冷启动闪错主题 | `main.tsx` 挂载前 data-theme 时序;非默认主题残余一帧可接受(尽力项) |
| 拖拽出现蓝底/文本选区 | 行/视图宿主 user-select:none 失效(硬编码色迁移回归),回查 T9 提交 |
| 复制路径无 toast | 非 WebView2 上下文 clipboard 不可用时的 Tauri 桥回退;浏览器 localhost 应直接走 navigator.clipboard |
| 焦点环看不见 | 确认用 Tab(非鼠标点击);三主题 --focus token 是否随迁 |
| 编辑态不出现 | 模态占线(modalBusy)期间被门控属预期;确认焦点不在输入框内 |
| 表头/菜单排序不同步 | 两入口共享 App 单一 `{key,dir}` 状态源;回查 T5 接线 |
| 抽屉列宽漂移 | 窗口极窄下的固定像素段(150/48/88/52/160/38)与百分比段并存,极窄属预期挤压;比例失恒再查 T10 |
