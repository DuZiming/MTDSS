# V3-3 冒烟测试手册(快捷目录系统)

配套 `docs/superpowers/specs/2026-11-05-mtdss-v3p3-favorites-design.md`(§3 产品语义/§5 Windows/§6 iOS)
与 `docs/superpowers/plans/2026-11-05-mtdss-v3p3-favorites.md`(Task 19 收尾编制)的逐项展开;
手册风格沿 `docs/smoke-v3p1.md`。自动化面(daemon 事件+golden 三端契约、三端契约/单测、
vitest 375、swift test 全量、cargo 全workspace)已全绿收口,本手册只收**实机判定**:
跨端同步时延、拖放手感与命中、多源扇出落盘、收件箱哨兵落箱——需用户在场/双端协作。

>
> ① Windows PC 装 V3-3 构建(v3p3 波产物);② iPhone 装 V3-3 包(TestFlight/开发包);

> 同名不同目录亦可)做同路径跨源着色项;PC 侧资源管理器可用(外部拖入/拖出项)。

## 2. 测试项清单

> 每项:前置 / 操作 / 预期;记录格式见文末。**实机场:用户在场协作**(双端操作/
> 资源管理器拖拽/看收件箱);标注 [操作台] 的条目用户不在场也可由操作者单独执行。

### A. 新建与添加成员(实机场:PC 单端可先做)

- [ ] **A1 新建快捷目录**(实机场)
  - 操作:左上角「新建」→ 下拉选「快捷目录」→ 命名对话框(空名禁提交)→ 确定;
    弹层空态「新建快捷目录」入口同验一遍。(R8 修订:侧栏标头 `+` 已随 §13.2 撤除,
    操作走新建下拉;侧栏若再现 `+` 即败。)
  - 预期:侧栏快捷行出现(0 成员合法);toast「已创建」;点入=空态引导「到设备浏览中
    添加目录」。
- [ ] **A2 设备浏览右键添加**(实机场)
  - 操作:浏览 iPhone(或本机)目录 → 目录行右键「添加到快捷目录」→ 弹层点选快捷。
  - 预期:toast「已加入 {名}」;快捷行无色点串(色点只在混合视图行/分组节头,
    §13.4),侧栏树展开该条目可见新成员目录节点;多选纯目录同项可用;选择含
    文件/混合选择时该项禁用。
- [ ] **A3 去重**(实机场,顺带)
  - 操作:同目录再添加一次进同一快捷。
  - 预期:「该目录已在其中」提示,成员数不增;写入失败(离线/只读)有错误 toast。
- [ ] **A4 多成员弹层(「存入哪个成员」)**(实机场)
  - 前置:快捷内已有 ≥2 成员(一远端一本机即可)。
  - 操作:向该快捷拖文件(内部拖拽)或粘贴。
  - 预期:弹「选择要存入的成员目录」(行=色点+设备名+路径);**离线成员行灰显禁选,
    悬停行可见「设备离线,不可选」**(T19 修⑤);点选即传。

### B. 混合/分组视图(实机场:双端在线)

- [ ] **B1 跨端打开混合视图**(实机场) *[§16:混合形态退场,主区=分类恒定页;「行首来源色点」词面废;渐进/面包屑/计数/返回本体照旧 → §I1]*
  - 操作:点侧栏快捷行 → 主区。
  - 预期:混合视图渐进出行(不等慢成员);面包屑=「快捷目录」根段+快捷名(下拉
    切换)两段(§14.3 命名空间,返工波 2 词面;H3 全形态);行首来源色点;状态栏
    计数随并入进度更新;「上一级」出快捷即设备层,后退可回快捷页。
- [ ] **B2 混合|分组切换**(实机场) *[§16 superseded:「混合|分组」切换已删,主区恒分类——本项退场跳过]*
  - 操作:工具栏「查看·组织」段切「分组」→ 重开客户端再看。
  - 预期:节=成员(节头=色点+设备名+路径末段);节序=成员添加序;偏好全局记忆
    (localStorage,重开保持;普通目录无此段=零回归)。
- [ ] **B3 同路径跨源着色**(实机场) *[§16:「行首色点分色」词面废(无色点);「两行并存不合并」本体继续有效,点击/右键互不串照旧]*
  - 前置:两成员目录各放同名文件(如 `报告.txt`)。
  - 预期:**两行并存不合并**,行首色点分色;分别点击/右键互不串(复合键选择)。
- [ ] **B4 离线成员桶**(实机场) *[§16:恒分类形态——离线=该节灰显+「离线」标注(节头单行)+底部注记,非「行从列表消失」;恢复秒级回列 → §I1]*
  - 操作:iPhone 断网(或杀 App)→ 看 PC 快捷视图;再恢复在线。
  - 预期:离线成员行从列表消失,底部「N 个成员离线或不可用」注记(悬停列设备名+路径
    明细);分组模式=该节灰显+「离线」标注无条目;恢复后秒级回列表(重连全量拉兜底)。
- [ ] **B5 钻取边界**(实机场,顺带)
  - 操作:双击成员子目录。
  - 预期:进 favdir 命名空间(面包屑=快捷目录>名>子目录,设备与原始路径隐藏;
    G6 同源);浏览器式历史后退可回快捷页。

### C. 外部拖入/粘贴/拖出(实机场:PC,资源管理器协作)

- [ ] **C1 Explorer 拖入单成员快捷**(实机场)
  - 操作:从资源管理器拖文件到快捷视图宿主/侧栏快捷行(单成员快捷)。
  - 预期:直传该成员(upload);**高分屏命中不偏移**(物理→CSS 像素换算已钉);
    冲突对话框开着时拖入不受理(占线门)。
- [ ] **C2 Explorer 拖入多成员快捷**(实机场)
  - 操作:拖文件到多成员快捷。
  - 预期:弹「存入哪个成员」→ 点选上传(同 A4 面)。
- [ ] **C3 拖入落点=分组节头/离线成员**(实机场,顺带)
  - 操作:分组模式下拖文件到某在线节头;再拖到离线成员的单成员快捷。
  - 预期:节头=直传该成员;离线目标=「设备离线,无法完成操作」提示不闪退
    (T19 修②,先说清不发 RPC)。
- [ ] **C4 粘贴进快捷**(实机场)
  - 操作:PC 内复制(或剪切)文件 → 快捷位 Ctrl+V。
  - 预期:单成员直进;多成员弹层;离线成员目标同 C3 提示。
- [ ] **C5 多选拖出窗外落盘(T19 修①,headline)**(实机场)
  - 前置:快捷含跨源选中(如本机+iPhone 各选若干行)。
  - 操作:快捷视图多选行 → 按住拖**出窗口**到桌面(或资源管理器某目录)松开。
  - 预期:落点目录收到**远端组**文件(download,多组=按来源分组 N 个传输,
    冲突挂起即停+「其余 N 组未发起」提示);**本机文件同落**(§14.2 返工波 2
    S5 修订:本机组 local_copy 复制进落点,不再组跳过);全选本机文件拖出 =
    真复制落盘(「所选均为本机文件」toast 已随 S5 退役);拖到不可解析处(如
    任务栏)→「请拖到桌面或使用下载到本机…」提示。
- [ ] **C6 dir 位拖出回归**(实机场,顺带)
  - 操作:普通目录(远端设备)选文件拖出窗口到桌面。
  - 预期:落盘照旧(V2 既有单源 download 语义,逐字节不回归)。

### D. 管理屏与删除(实机场:PC)

- [ ] **D1 管理屏移除成员**(实机场)
  - 操作:侧栏快捷行右键「管理成员」→ 成员列表(色点+设备名+路径)「移除」一枚;
    正浏览该快捷时看主区。
  - 预期:toast「已移除」;管理屏成员行 -1;Windows 侧栏该成员内容行**收起
    重展开后消隐**(树位缓存为引擎边界,iOS 即时消隐——重展开后才消隐属预期
    非败);正浏览时混合视图该成员行即时消失(重扇出);设备不在快照的成员行=
    「设备已移除」标注可清。
- [ ] **D2 重命名**(实机场)
  - 操作:右键「重命名」→ 预填旧名 → 改名保存。
  - 预期:toast「已重命名」;侧栏/面包屑同步;busy 在途 Esc/遮罩不可取消(T8 门)。
- [ ] **D3 删除快捷**(实机场)
  - 操作:管理屏底部「删除快捷目录」(或右键「删除快捷」)→ 确认弹层。
  - 预期:确认文案=「只解除链接,不删除任何文件。删除 {名}?」;确认后快捷消失、
    toast「已删除」;**远端/本机文件原地不动**(到资源管理器复核);正浏览该快捷
    则回设备视图。
- [ ] **D4 叠层 Esc 单关(T19 修⑦)**(实机场,顺带)
  - 操作:管理屏上点「删除快捷目录」开确认 → 按 Esc。
  - 预期:**只关确认弹层,管理屏保留**;再按 Esc 关管理屏(不连关)。

### E. 跨端互推(实机场:双端)

- [ ] **E1 PC→iOS 秒级重拉**(实机场)
  - 操作:PC 新建快捷+添加成员(或重命名)→ 看 iPhone「快捷目录」标签。
  - 预期:双端在线时数秒内跟线(data_changed 通告→kv.get 全量替换);杀过的 App
    重进后拉到最新(重连兜底)。
- [ ] **E2 iOS→PC 秒级重拉**(实机场)
  - 操作:iPhone 上重命名/添加成员(经 F3/F4)→ 看 PC 侧栏。
  - 预期:秒级同变;kv.put 失败(断网试)时本地保旧值+报错 toast,恢复后可重试。
- [ ] **E3 并发编辑后写者胜**(实机场,可选)
  - 操作:两端同时各改一处(如一端改名、另一端加成员)尽量同时保存。
  - 预期:后写者胜,先写者改动丢失(整单 LWW 已知语义,记录现象即可,不算失败)。

### F. iOS 真机项(实机场:iPhone)

- [ ] **F1 快捷目录标签根列表**(实机场)
  - 操作:「快捷目录」标签:看根列表;左滑快捷行;「···」菜单。
  - 预期:收件箱根行置顶 + 快捷行(名,无色点串);点快捷行推混合页;左滑=
    [管理, 删除快捷];「···」含「新建快捷目录」;清单空=「还没有快捷目录」+新建行;
    readOnly 档=只读提示行且清单行禁点(T19 修⑥)。
- [ ] **F2 混合页动作+收件箱哨兵落箱(T15 concern②,headline)**(实机场)
  - 操作:混合页选择若干远端行 → 「下载」;再到 PC(或对端)看收件目录;
    「发送」选在线设备;「删除」看远端门。
  - 预期:下载经 inbox 哨兵(`dir="inbox"`)落**对端收件箱目录**(引擎解析 recv_dir,
    文件真实落箱可开核);发送=对端收件箱落箱;删除:远端门(allowRemoteDelete)

- [ ] **F3 添加成员(远端浏览)**(实机场)

  - 预期:toast「已加入 {名}」;「该目录已在其中」收口;文件行/混合选择不出该项;
    失败(put 拒)=「操作失败,请重试。」alert 留驻可重试。
- [ ] **F4 管理(管理屏)**(实机场)
  - 操作:左滑「管理」→ 重命名(保存)/成员行移除/底部删除快捷(确认)。
  - 预期:改名后根列表/混合页标题同变;移除即清单 -1;删除确认文案同 D3 口径
    (只解除链接);删除后正推入的混合页弹回。
- [ ] **F5 已知边界:混合页钻取无「快捷」入口**(实机场,记录项)
  - 操作:混合页双击(点按)成员子目录钻取 → 看远端浏览页左滑/底栏。
  - 预期:**无「快捷」添加入口**(本波有意边界,不在验收线);用户可从「设备」标签
    进入浏览添加(同 F3);记录现象不算失败。
