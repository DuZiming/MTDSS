### A. 引擎验收线(实机场:PC ↔ MIX 3 ↔ iPhone;中继三层 + 并发 + 收尾票)

- [ ] **A1 接收并发:双对端同发并行,时间线重叠**(验收线 1)
  - 前置:PC 在线为接收端;MIX 3 与 iPhone(或 MIX 3 + 另一 PC 构建)各备小文件数枚。
  - 操作:①两端**几乎同时**(背靠背 <1s 间隔)向 PC 各发一枚小文件;②PC 任务抽屉看两卡
    进度推进;③PC daemon 日志看两轮时间线与两行 `接收完成`。
  - 预期:②两卡**同时推进**(进度事件交错,非一卡走完另一卡才动);③两轮时间线重叠,
    总墙钟 ≈ max(单轮) 而非 sum;两件全达、落盘完整。
    注:同设备并发第二笔天然落打洞臂(XferSlots 按设备单槽语义,发送端镜像,预期行为
    不算失败);并发上限 3,第三笔起排队属设计。
- [ ] **A2 armed 直进中继:物理不通对第二笔起无打洞等待**(实机场,headline;验收线 2 前半)
  - 前置:差网场打洞必败对(双端新构建);大文件备用。
  - 操作:①发**首笔**:盯日志 `打洞穷尽,armed 记忆建立` → `中继兜底已建立`(穷尽即切,
    无「穷尽后才分配」串行段,总连接时间 ≈ 打洞预算 10-30s);②**紧接着发第二笔**:
    盯 `armed 记忆命中:跳直连段直进中继`,记录连接耗时;③对照两笔耗时。
  - 预期:②第二笔**秒级直进中继**(armed 命中行 + 直分配,无 `candidates:` 打洞段、
    无 10-30s 打洞等待);③第二笔连接耗时 ≪ 首笔(量级 1-2s vs 10-30s);作业卡中继
    角标照旧。注:①armed 记忆范围=仅传输面(ctrl/浏览不受影响);②TTL 15min——静默
    >15min 后首笔重缴学费、`armed 建立` 行复现 = 设计预期非回归;③资格不在手(中继
    全局停用)则 armed 不生效、直连穷尽后失败照旧(不上报「中继优先」误语义)。
- [ ] **A3 并行预备即切:首笔打洞预算内切换**(验收线 2 前半;A2 首笔单列拆段)
  - 操作:A2 首笔全程计时拆段;另对**好网络对**发一枚作直连形态对照。
  - 预期:①差网对:`中继兜底已建立` 在穷尽判决后**立即**出现(预备任务打洞开局 3s
    起跑,分配+互拨与打洞并行完成;无「穷尽后才分配再互拨」的 10-20s 串行长尾);
    ②好网络对:直连胜出,debug 行 `预备会话弃单:显式释放(直连胜出/轮亡收口)` 在场、
    零 `中继兜底已建立`。**旧服务端注记**:弃单释放帧可能收 err(3) 回包——debug 行
    `释放帧归因的旧服务端 err(3),容忍`(信令连接不断,抑制窗 10s);会话滞留 ≤120s
    服务端空闲回收 = **设计容忍非失败**(VPS 升级 RelayRelease 后消除)。
- [ ] **A4 探洞回切:中继传输中直连恢复 → 关半连 + 重试落直连 + 位图零重发**(实机场,
      **headline**;验收线 2 后半)
  - 前置:A2 的 armed 中继传输**在途**(大文件 ≥200MB 保证回切窗内传不完);发送端备
    完整原件。
  - 操作:①中继传输在途时**恢复直连条件**(PC 从对称 NAT 侧切回家宽/常态网络);
    ②PC 与对端日志盯 30s 节奏探洞(`warm 预热成功` 频次;活跃中继轮豁免冷却窗)与
    **`回切:关闭中继半连,重试轮落直连`**;③观察作业卡:中断后重试轮落直连/暖臂
    (无 `candidates:` 行),进度**累计不回落**(A7 口径),已完成字节**零重发**
    (速率回升 + 落盘 md5 对拍);④等作业 done,核落盘完整。
  - 预期:②直连恢复后**数分钟内**自动回切(探洞 ~30s/发;一发一代际闸);③重试轮
    位图续传只补缺口(总传输量 ≈ 文件大小,非倍增);md5 一致;④done 落盘完整。
    注:回切在接收侧呈现为「一轮可重试失败」——下载绑定卡保持 running、匿名卡靠幂等
    重绑不新增失败卡(既有语义);回切行出现在探洞方,对端呈「在途轮网络失败 → 重试轮
    落暖臂」两侧任一见回切行即锚。
- [ ] **A5 回切防振荡:直连再死重新穷尽**(验收线 3 防振荡面)
  - 操作:A4 回切完成后,①再次制造直连死亡(PC 切回对称 NAT 侧);②再发一枚。
  - 预期:重走穷尽 → `打洞穷尽,armed 记忆建立` 复现(代际推进)→ 中继直进;**不出现**
    直连/中继高频乒乓(一发一代际;回切后再 armed 需一次新鲜穷尽)。
- [ ] **A6 匿名卡持久化:重启收件史在场 + 新卡不撞号**(验收线 5)
  - 操作:①PC 接收若干件(含对端直发收件箱的匿名卡形态);②重启 PC daemon(退出
    Synshu 重开);③开任务抽屉看收件史;④再收一枚新件看新卡 id。
  - 预期:③重启后收件史**在场**(含 incoming 终态;持久上限 100);④新卡 id 与持久
    记录不撞号(持久计数器);非终态重启标 interrupted(既有)。
- [ ] **A7 续传进度累计:中断重发进度不回落**(验收线 5)
  - 操作:①大文件传输中断(杀发送端 daemon 或断网制造失败轮);②重发同件(重试轮);
    ③任务卡进度全程盯到底。
  - 预期:重试轮进度从**已收字节累计**起(事件序列单调不回落;UI/卡片/事件三面同源),
    无「从 0 重来」观感;终态 done 落盘完整。
- [ ] **A8 收件箱子目录直发:`/收件箱/子` 落发布树子目录**(验收线 5)
  - 操作:①PC→MIX 3 发一枚,target_dir 构造 `/收件箱/子`(地址栏/路径面);②MIX 3
    收件箱看落点;③md5 对拍;④根 `/收件箱` 直发一枚回归对照。
  - 预期:①落**发布树 子/ 目录**(非字面路径失败、非根平铺);③一致;④根哨兵行为
    不变(v3p5b §E6 已钉,桌面直发手机收件箱不再 EROFS)。
