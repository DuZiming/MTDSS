这一版落实的东西
  • 侧栏 = 树:可整棵点「MTDSS设备」节点在右侧看设备列表,也可逐级展开;点目录即在右侧展示内容

「查看」菜单的三种模式 —— 默认用哪种?(可点击)

A

平铺(默认)

大图标网格,名称在图标下方。像打开「此电脑」时的样子,适合文件不多、看缩略感觉。

B

列表(默认)

紧凑单列,小图标+名称,一屏能看很多项。适合目录里文件多的时候。

C

详细信息(默认)

多列表格:名称/修改日期/类型/大小,可点列头按名称排序。像 Windows 详细信息视图。
