## 1. 意图与范围

V3-4 = **安卓 App 按 iOS v1(含 V3-3 终态)的架构/操作/交互/视觉整体重写**,一次装入伞形 §7 对齐八项 + Windows 同步四项 + V3-1 顺延的安卓扫码器 UI + V3-3 顺延的安卓快捷目录落位。引擎契约层(golden 单一真源)零破坏,分叉收敛在平台接线层与 UI 层。

**范围清单**(验收线全项):
1. 安卓四标签壳 + 全部屏幕重写(§3 逐屏映射);
2. 对齐八项(§4):SAF 根注入守卫 / 删除门三端 / 照片虚拟根 / 分享暂存可重试 / 显示隐藏 / 设备名设置 / 收件箱置顶 / 调度显示;
3. 附加顺延项:扫码器 UI(V3-1)、快捷目录(V3-3)、任务列表最新在上(§8 V3-5 项的安卓半边)、安卓任务徽章色对齐 iOS 方向语义(§4.8);
4. Windows 四项(§5):删除门 / 可选信任目录模式 / 显示隐藏 / 设备名设置迁设置面;顺手票:混合视图 truncated 浮面提示;
5. 冒烟清单 `docs/smoke-v3p4.md` + MIX 3 真机场。

### 1.1 对伞形反目标的用户修订(2026-11-08 裁定)

伞形 §2 反目标「三端像素级一致:安卓视觉保持 Material 3 原生,不做 iOS 高仿」——**用户在 V3-4 视觉稿评审中明确推翻视觉半边**:「我要的就是和 ios 一样」。修订后口径:

- **架构/操作/交互**:对齐 iOS(伞形原文,不变);
- **视觉**:对齐 iOS 文件 App 范式(白底极简、玻璃胶囊、发丝线、行结构规格),**不再以 Material 3 视觉为准**;
- **工程实现底座**:仍是 Kotlin + Compose(M3 组件库可用作实现件,主题 token 全量自定义为 iOS 规格值);**不引入 SwiftUI/跨端框架,引擎不重写**(伞形该两条不变)。

- **弹窗**:居中 alert(毛玻璃卡 272dp、圆角 14、标题 16.5·600/正文 13/按钮行发丝分隔,破坏红字/主操作蓝粗);sheet 半屏(拖把手 36×5、圆角 16 顶)。
- **返回**:安卓系统返回手势/键 = 页面回退;顶栏双箭头 = 目录级前进/后退(非系统返回)。

## 4. 对齐八项 + 附加项(现状 → 目标 → 实施面)

### 4.1 被浏览授权根守卫 + 安卓服务桥(伞形 §7-1;2026-11-08 builder check 后修订)
- **现状**(builder check 核实):RootGuard = 纯词法路径前缀守卫,`DaemonOpts::authorized_roots` 在 `Daemon::start` 一次性注入;安卓 bin 硬编码 `None` 且 `photo_serve: false`。引擎为独立进程,**读不了任何 SAF 内容**(content:// 仅 App 进程可解析);既有 fd 桥三原语(0x01/0x04/0x05)只服务安卓**主动发起**的发送与收件——「对端发起的浏览/下载安卓内容」面在引擎中**不存在**;今天对端浏览安卓 = 引擎对 App 沙箱的直读视图。
- **目标语义**(验收线;伞形 §7-1「对端见合成根列表」+ iOS 基准钉死):对端 `list_remote` 顶层只见**合成根列表** = 收件箱 + SAF 授权根 + 照片图库(§4.3);合成根内**可浏览/可下载/可删除**(删除受 §4.2 门,默认关);清单外路径被守卫拒;授权根增删即生效;App 私有暂存区(§4.4)**不进授权集、对端不可见**。
- **实施面(builder check 后定案;原「引擎最小增量」框架作废)**:
  1. **安卓服务桥** = 照片桥(photo.rs + 0x06/0x07)模式的**泛化**:引擎新增「App 应答式文件服务面」——对端发起到安卓 SAF vpath(合成根命名空间)的 list/read/delete 路由 App 进程实现(Kotlin SAF/MediaStore),守卫对 vpath 命名空间生效。**照片桥量级或以上的真实引擎增量**(含 golden 增量与 e2e);通道号沿 fdpass 纪律新立;
  2. **`roots.set` IPC(热注册)**:注册 `{vpath, 对端可见性}` 集,热生效(替代 bin 硬编码;Windows §5-2 共用);守卫集与对端可见列表**分离**(隐藏根语义随 op 引入——暂存区可授权而不可见,§4.4 桥式发送下则根本不进集);
  3. 授权根账本(既有 RootsStore)→ App 启动/变更时经 `roots.set` 同步;收件箱恒在。
- **尺度警示**:本项为全波最大单体(工作包 G 由「注入+接线」升格为「桥构建」)。**唯一可退档**(用户裁剪时):对端对安卓合成根只读(浏览/下载),删除桥后置——门默认关,退档不改变默认行为。

### 4.2 允许删除远端文件(伞形 §7-2)
- **目标**:三端统一安全门,**默认全关**;门只收 UI 面(入口显隐),引擎 ctrl delete 契约不变;本地删除不设门;远端删除(行左滑/选择底栏)受门;删除 = 整树语义 + 居中确认(文件夹形文案「删除文件夹及内容?」)。
- **安卓**:设置页开关 + 新 UI 接线;**Windows**:设置面补同款开关(默认关),远端删除入口(右键/选中删除)受门,既有回收站确认梯保留。
- **远端删除安卓目标**(builder check 补面):ctrl delete 经 §4.1 服务桥路由 Kotlin 删除(App 属主 SAF deleteRow = 硬删,MIUI 语义库口径);门默认关 = 桥删除面平时不可达。

### 4.3 相册照片虚拟根 `/照片图库`(伞形 §7-3)
- **现状**:引擎 photo.rs 平台无关现成;iOS 已接(0x06/0x07 照片桥)。
- **目标**:安卓作为**被浏览方**出现 `/照片图库` 只读虚拟根(对端 = Windows/iOS/其他安卓可浏览下载);**权限即数据面**(对齐 iOS):未授权时虚拟根不出现在合成根列表,不出现「未授权」占位;虚拟根只读(下载/转发可,删除/写入拒)。
- **权限矩阵**(builder check 修正;minSdk 29 无 ≤28 面):API 33+ = READ_MEDIA_IMAGES + READ_MEDIA_VIDEO;API 29-32 = READ_EXTERNAL_STORAGE(**MIX 3 冒烟机在此档**,MIUI 授权路径入冒烟清单)。**本波为 App 首次引入运行时存储权限**——伞形 §7-3 已含授权,商店合规姿态变化记录在案。
- **实施面**:Kotlin 照片应答器接 `fs.photo_list`/`fs.photo_export`(MediaStore 查询+导出),fdpass 通道号对齐 iOS(0x06/0x07);golden 契约 iOS 已铺,安卓为消费端对齐。

### 4.4 分享扩展:暂存转交可重试(伞形 §7-4)
- **现状**:ShareActivity 一次性 content URI,中断 = 「源已不存在」。
- **目标**(对齐 iOS 方案 A 形态):分享到达 → **立即拷贝进 App 私有暂存区**(不持 content URI)→ 入队落盘 → 转交主 App 发送;失败 = 传输列表「分享转交失败」行 + 重试(重选设备即重发);可跨进程死亡重试(暂存件在场)。尺寸守卫:拷后校验,盘损拒发(对齐 iOS SendStaging 语义)。
- **实施面**:ShareActivity 重做(A 皮肤设备列表 + 暂存拷贝 + 队列 json);主 App 前台/登录时消费;暂存区 = App 私有 home(不落 SAF 公开区);**暂存件发送走桥式(0x01 request_source,App 作源)——不注入引擎路径命名空间、不进授权集、对端不可见**(iOS 因扩展内无 fd 提供方被迫路径形;安卓本有 0x01 通道,iOS 先例不适用);**iOS 的扩展直发引擎方案不移植**(安卓主 App 常被杀,语义 = 队列+拉起/等待主 App 消费,失败行可见)。

### 4.5 显示隐藏项(伞形 §7-5)
- 安卓/Windows 补设置开关(**默认关**);App 侧过滤 dotfiles(daemon list 不滤,UI 层滤——iOS 同口径);快捷目录树子级同滤。

### 4.6 设备名设置(伞形 §7-6)
- 安卓:从登录表单迁到设置页(登录页注脚只读);Windows:从登录高级选项迁到设置面;改名**下次登录生效**(既有语义不变)。

### 4.7 收件箱置顶常用区(伞形 §7-8)
- 安卓快捷目录根页收件箱置顶(DirNode 对齐成员,可展开/可点入);服务端/引擎零改(V3-3 已铺)。
