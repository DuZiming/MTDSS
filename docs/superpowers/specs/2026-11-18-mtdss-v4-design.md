# MTDSS(Synshu)V4 伞形设计:亮点功能与公开上线

- 日期:2026-11-18
- 状态:待用户批准(brainstorm 定稿 2026-11-18;builder check 五问已闭环:一问用户钦定 iOS 先 TestFlight 后 App Store,四问入裁量 #14-17)
- 前置:V3 全线收官(V3-1~7 合并,Synshu 1.4.0 五端发版,VPS 服务端 fdae9e45)
- 性质:伞形设计,同 V3 模式——每波独立 spec → 实施计划 → TDD → 冒烟清单 → 真机/实机场

## 0. 定位与意图

V3 把 MTDSS 从自用工具升级为「邀请制小规模产品」(admin 开号、朋友/同事/视频引流)。
V4 往前推一大步:**大部分人可自助使用的公开产品**——但路径是**先把产品做强,再开门**:
先交付两个亮点功能(免下载预览、超级剪切板)与平台补全(Linux/macOS 图形端),
最后以产品化上线波(自助注册+官网+运营后台+发布管理)收官,版本落 2.0.0 公开上线。

在上线波之前,注册仍维持邀请制(admin 开号),新功能在受邀用户群中实盘打磨。

## 1. 目标 / 非目标 / 反目标

**目标**:
- 免下载预览:音视频流式、图片查看器、PDF/Word/Excel/PPT/txt/md/代码内嵌查看,平铺视图缩略图
- 超级剪切板:多设备共享剪切板,本地优先、离线可插入、上线自动合并
- 平台补全:Linux/macOS 图形端 + 打包 + 手动更新(含既有新功能的对齐)
- 自助使用闭环(上线波):新用户从官网/下载页 → 安装 → 客户端内自助注册(不跳官网)→ 多端互传,全程零人工
- 运营自助(上线波):网页后台完成账号管理、新包发布管理、运营数据看板,替代 admin CLI + 手工 VPS 流程

**非目标(V4 明确不做)**:
- APNs/FCM 推送(V3 裁定维持;剪切板已设计成不需要)
- deb/rpm 仓库;macOS Intel 架构;macOS 签名+公证(接受首开引导,同 Windows SmartScreen 先例)
- Linux/macOS 应用内自动更新(走 B 档手动;Windows 维持现有全自动链)
- 网页版账号门户(注册/登录/管理全在客户端与运营后台)
- office 像素级还原;office 编辑(只查看)
- 老二进制格式(.doc/.xls/.ppt)预览(提示下载打开)
- 剪切板内容落服务端存储(本地优先,见 §5)
- ~~移动端平铺视图~~(2026-11-18 mockup 波改判:**移动端平铺转正**=列表默认+菜单可切平铺一行 4 个,V4-1 范围内)

**反目标**:
- 剪切板明文内容出现在服务端(只过本地+设备间同步)
- 预览强制用户显式「下载完才能看」(docx/xlsx/pptx 的后台静默整取不算——UI 无下载动作)
- 注册被滥用无刹车:上线波必须带注册总开关与限速,运营可一键止血

## 3. V4-1 免下载预览+缩略图(含平铺视图)

### 3.1 引擎原语:回环 HTTP Range 口
daemon 起仅回环(127.0.0.1,随机口+token,仅本机)的 HTTP 服务,对**远端文件的字节区间**支持 Range;后端接远端按需读,走 V3-5 复用/传输连接,带预读窗口。所有预览消费这一个标准口(桌面 `<video>`、移动 AVPlayer/ExoPlayer、pdf.js、图片查看器、web 预览器)。

### 3.2 共享 web 预览器(先落 Win/Android/iOS 三端;Linux/macOS 随 V4-3 挂载)
一个 JS bundle(pdf.js+docx/xlsx/pptx 渲染+md/代码高亮),桌面=主窗口内,安卓=WebView,iOS=WKWebView。仅查看无编辑。

| 格式 | 传输 | 展示 |
|---|---|---|
| 视频/音频 | 真流式(range) | 桌面 webview 播放器/AVPlayer/ExoPlayer |
| 图片 | 缩略图→原文件渐进 | 各端内嵌图片查看器(自集成) |
| PDF | 真分段:按需取页字节 | pdf.js,先出首页,滚动/「更多」续取 |
| docx/xlsx/pptx | 后台静默整取(文档通常小,秒级)+ 逐页/逐表渲染 | 先出前几页/前若干行,「查看更多」往下翻 |
| txt/md/代码 | 头部取+渐进 | md 渲染+语法高亮 |

- docx/xlsx/pptx 为 zip 结构,传输层物理上无法按字节分段;「分段」体现在渲染翻页(UI 无下载动作)
- xlsx:多 sheet/大表先渲首屏行,续翻续渲
- 源端离线=预览不可用,明确提示

### 3.3 缩略图与平铺视图
- **源端生成+缓存,覆盖五端**(文件在哪端就在哪端生成):桌面=daemon 内图像解码(含 HEIC/libheif 级依赖,许可与体积归波内);移动=平台 API 出帧(Android MediaMetadataRetriever/iOS AVAssetImageGenerator)经既有 fd-pass/桥先例喂回引擎。移动端虽不做平铺视图,但**作为源端必须出真缩略图**(PC 平铺浏览手机相册是核心场景)——2026-11-18 补:移动端 UI 平铺亦转正,见下
- 图片真缩略图、视频抽帧、其余=类型图标;经同一 HTTP 口
- **平铺视图改版=缩略图网格,五端统一**(V3-6 移出的专题在此转正):桌面=Explorer 式磁贴(现行 folder/filetint 图标体系放大、缩略图等比不裁切、名字+第二行小字、三档大小、记住每目录形态);**移动端=列表为默认+菜单可切平铺(一行 4 个,上图标下文字,记住选择)**;移动列表行同步升级缩略图
- 剪切板「文件封面」复用同一基建(V4-2 消费)

### 3.4 验收线
Win/Android/iOS 对远端文件免下载内嵌预览(格式矩阵覆盖);视频可拖进度条;PDF 翻页续载;office 先出前几页可续翻;桌面平铺视图出缩略图;移动端平铺可切(列表默认)且列表行带缩略图。

## 4. V4-2 超级剪切板

### 4.1 存储与同步模型(本地优先)
- 每终端本地存完整历史(文字条目全量;文件条目=文件名+缩略图元数据);**服务端零存储**
- 同步=设备间:在线增量互通,离线照常本地插入,上线自动合并(并集去重;每条=设备+序号/时间戳,追加式无编辑冲突)
- 离线终端上线后从任一仍持有该条的终端合并补齐;若所有终端已轮换删除则不可恢复(桌面常驻,实践罕见)
- **OFF 设备仍被动接收**:同步不因本机开关关闭,远端条目照常进本地历史(超级剪切板窗口内容跨端一致);开关只管「不自动捕获本机系统剪切板」
- **新设备进场**:受信终端登录后补齐对端现存全量历史(信任级与 V3-1 受信终端一致;历史保留上限使量有界)
- 历史有上限/保留期(数值归波内);防回声=本机写入系统剪切板不触发再捕获

### 4.2 开关语义
- **自动捕获 ON**:PC Ctrl+C/复制→直入并同步;文字=内容即达(桌面常驻端实际已写入);文件=只同步名+缩略图,内容不传,**粘贴时才从源终端拉取**(复用传输引擎);移动端切入前台自动读剪切板(iOS 弹「允许粘贴」),仅文字
- **OFF**:不碰系统剪切板;可手动将内容粘贴入/文件复制入超级剪切板,一样同步

### 4.3 UI
- 桌面:顶栏入口→超级剪切板窗口;左侧历史倒序(最新在上),右侧选中内容预览(默认最新)+复制按钮
- 移动端入口位置待波内 mockup 定
- 文件条目粘贴时源端须在线;离线=提示不可拉取

### 4.4 验收线
PC A 复制文字→B 立即可粘贴;文件复制→对端见封面→粘贴拉真件(离线源=明确提示);离线插入上线合并;各端历史最终一致。

## 5. V4-3 Linux/macOS 图形端

- Tauri UI 跨平台落地:现有 React+Tauri 面向 Windows 调校;Linux(webkit2gtk)/macOS(WKWebView)差异面=托盘/自启/路径/深浅色/快捷键/安装器;引擎零改动(daemon 已支持两平台)
- 打包:Linux=AppImage+tar;macOS=arm64 dmg;版本联动沿用既有四处版本文件流程
- 更新 B 档:应用内「检查更新」→manifest 对比→提示→一键开下载页;不自动装
- CI:linux/macos runner 构建两包;冒烟=既有 linux-testvm(补桌面环境;或另备带桌面的 Linux 实机/vm,设备矩阵归波内 spec)+ Mac mini 真机
- 验收线:Linux/macOS 图形端功能面对齐 Windows 现状(登录/互见/浏览/收发/任务/快捷目录/检查更新),**并挂载 V4-1 预览器与 V4-2 剪切板**(对齐=含本 V4 已交付的全部新功能)

## 6. V4-4 产品化上线(收官波;公开上线验收线)

### 6.1 客户端自助注册
- 三端登录页:输入邮箱→发码→输码;**账号不存在=自动创建并登录**(登录即注册),无独立注册页、不设密码
- 邮箱码真实投递沿用阿里云邮件推送(V3-1 已接)
- 首次登录进入受信终端流程沿用 V3-1 语义(第一台自动受信)

### 6.2 服务端注册与防滥用
- 注册开关:服务端配置+后台一键开/关(运营安全阀,默认开)
- 防滥用三层:per-IP/per-email 发码限速(V3-1 已有基础)+ 一次性邮箱域名黑名单 + 新账号默认配额(设备上限/中继并发/带宽沿用现值,后台可逐号调)
- 配额数值、黑名单维护界面归波内 spec

### 6.3 官网(静态)
- 内容:产品介绍/五端下载/FAQ/更新日志;营销落地页形态
- 部署:与现有 VPS Caddy 同源;构建管线进 CI
- 无任何账号/登录功能

### 6.4 网页运营后台
- 账号管理:搜索/详情/设备清单/解绑/封禁/配额调整(替代 admin CLI 日常操作)
- **新包发布管理**:后台管理发布流程,但**更新签名私钥不上 VPS**——运营侧本机 mtdss-sign 预签,后台出「待签产物清单→上传签名 manifest→发布/回滚」流(信任根不落服务器,沿 V3-1「凭据经环境注入不落库」先例);替代手工传 VPS;顺带治「CI 产物烤 .invalid」历史票(发布通道统一走后台)
- 运营看板:注册量/活跃设备/在线数/中继带宽用量/各版本占用率;数据=服务端既有状态+事件计数,不引入重型分析栈
- 后台仅运营者使用(admin 账号体系已有);前端技术栈归波内 spec

### 6.5 验收线(=公开上线)
新用户从下载页→安装→自助注册→双端互传全程零人工;运营在后台完成封号/解绑/发版/回滚全流程;看板能看大盘;**版本 2.0.0 发布**。iOS 分发按 TestFlight 过渡口径(已知限制:1 万上限/构建 90 天过期,接受;App Store 上架=V4 后既定里程碑)。
