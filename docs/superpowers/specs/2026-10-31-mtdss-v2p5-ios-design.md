# MTDSS V2-P5 iOS 客户端 设计稿

日期:2026-10-31 | 状态:待 builder 评审 → 待用户批准
来源:2026-10-30/31 brainstorm(含六轮视觉 mockup 定稿),决策人为用户本人,记录人为 Claude。

## 1. 意图与背景

V2 五阶段的收官项目:为首批真实用户中占比约半数的 iPhone 用户交付原生 iOS 客户端。引擎与产品语义已在 V2-P1(中继)、P2(跨会话任务)、P3/P4a(安卓客户端+收件暂存)全部落地并实盘验证;P5 只需把已验证的引擎形态搬进 iOS 进程模型,产品语义原样承接。

前置条件(均已就绪):Apple 开发者账号(个人)已批;Mac mini(Apple Silicon,兼构建机)在位;`mtdss.top` 域名与 VPS 产线在役。

**为什么现在**:P4b 已收官、打包轮 1.1.0 物料全备,Windows/安卓/服务端三线齐备,iOS 是最后一块;账号审批这一纯前置时间已消化。

## 2. 目标 / 非目标 / 反目标

**目标(v1)**:
- 功能面对齐安卓 v1:登录、设备互见、浏览远端、双向收发、任务列表/中断重发、系统分享入口
- TestFlight 外部组内测先行,首批用户即装即用
- UI 达到"苹果原生精品"水准(本轮用户钦定为一等目标,安卓 v1 的"能用薄壳"教训不重演)

**非目标(v1 明确不做)**:
- App Store 公开上架(后续里程碑;涉及评审与卖家名展示策略)
- App 内自更新(商店/TestFlight 接管更新;iOS 也不允许自更新)
- 平铺/网格视图(用户裁定"先不做页面模式切换",全 App 仅列表态;票留后续版本)
- 扫码登录(我的页左上角放图标占位)、常用目录管理(首页只保留收件箱一枚)、联系我们/为我打分/我的权益(占位页)
- 静默推送后台自动发送(APNs 基建,票 C → v1.x)、分享扩展内小文件直发(性价比低,否决)
- iPad 适配、横屏、watchOS、Live Activity、推送通知、多语言(中文单语)

**反目标**:
- 任何"桌面范式"的移植:信息密度、行高、控件尺寸必须按 iOS 触控习惯重做(用户在 mockup 轮对 30px 行高桌面列表明确否决)
- 自绘主题系统/品牌脸移植(用户在 A/B/C 三方向中明确选择 A:纯原生 HIG,理由"看着习惯、不花里胡哨")
- 引擎重写或 Swift 直译引擎:必须复用 Rust 引擎(零 FFI 大改,同安卓路线)

## 3. 产品语义(承接安卓已裁定,逐条平移)

| 语义 | 内容 |
|---|---|
| 前台=在线 | 无常驻、无后台保活;切后台/熄屏,传输死活随系统(短窗口内断,标「中断」) |
| 不自动续传 | 任务列表是一等界面;中断后手动「重新发起」(P2 语义:翻新同记录换新 job_id,有续传基础则续传) |
| 收件 = 私有暂存+完成发布 | P4a 语义:iOS 形态=收件中文件落 App 私有 `.mtdss` 暂存区,完成后 move+rename 发布进收件箱;杀 App 中间态不可见 |
| 收件箱 | 每端默认收件目录;iOS=App Documents(开 UIFileSharingEnabled/LSSupportsOpeningDocumentsInPlace,文件 App 可见);**默认对其他设备可见可浏览,不可删除** |
| 发送免选目录 | 发送给任意设备默认落对方收件箱——移动端减一跳(用户钦定产品原则) |
| 发送/转发/下载 | 发送=本机→远端收件箱(常用目录页操作);转发=远端A→远端B 调度(设备页浏览 A 时操作);下载=远端→本机收件箱 |
| 授权目录集(2026-10-31 用户定案) | 授权集 = **收件箱(App 初始授权,不可删)+ 信任目录(用户经设置添加)**;授权集内引擎可读 → ①其他设备可浏览进来 ②可作 App 内发送源。第一标签=授权目录列表(收件箱恒在,信任目录添加后自动出现)。**发送路径仅两条**:授权目录内浏览多选发送、系统分享扩展;App 内文件选择器直发不做 |
| 信任目录 | 出站白名单+发送授权(≈安卓 SAF 授权根;iOS 用安全域书签实现);管理入口在设置页,「+」开系统目录选择器选定即授权 |
| 备份策略(用户裁定) | 收件箱是系统真实目录,**不干预备份**(isExcludedFromBackup 不设,用户自己在 iCloud 备份里选);暂存区 `.mtdss` 与分享队列属 App 内部中间态,排除备份 |
| 隐藏项 | 浏览时默认隐藏对端隐藏目录/文件,设置有开关,只影响显示不影响传输 |
- 传输完成 | 发本地通知(无推送)

**发行前置物料**:TestFlight 外部组需隐私政策 URL——记录人起草(涉及邮箱/设备名/中继元数据表述)→**用户过目**→挂 `mtdss.top/privacy` 静态页(2026-10-31 用户定案);App 图标 v1 用简洁占位(记录人出),品牌资产留票;出口合规按标准加密豁免惯例勾选。

## 4. UI 设计语言(2026-10-31 定稿,mockup 全存档)

**总范式**:苹果原生 HIG,白底极简扁平,跟系统深浅,系统蓝,iOS 26 Liquid Glass 时代控件。四标签 + 悬浮玻璃胶囊标签栏。**零自绘主题系统**(工程红利:不建 token 体系)。

**设计基准**:440×956pt(用户测试机 iPhone 16 Pro Max 2868×1320÷3);字号行高按系统规格(大标题 34 / 正文 17 / 列表行 56-64 / 副文 12.5-13)。

### 4.1 浏览页模板(收件箱/信任目录/远端浏览共用)
- 顶栏:左**返回+前进双箭头**(SF chevron 粗圆头 3.2 描边,返回蓝/前进浅灰禁用;前进=返回后可再进入,浏览器式导航历史)、**标题绝对居中**(整页 50% 定位)、右上**「···」圆钮**
- 标签根页无箭头(仅三点);推入页显示返回
- 顶栏下方**搜索框**(灰底圆角+放大镜;按名称过滤当前列表)
- 行:通栏、细分割线从行首起;**文件夹=左侧蓝色 › + 蓝色文件夹图标;文件=无箭头 + 问号文档图标**(统一,不按类型区分,用户裁定);副文「日期 - N 项」(文件为「日期 - 大小」)
- **「N 项」沉底**(列表尾/底随滚动)
- 「···」菜单:选择 / 排序(名称、日期、大小、种类);设备列表根页为「刷新」

### 4.2 选择模式(「···」→选择 进入)
- 顶栏:**全选(左)/ 居中「N 项」/ 右蓝色圆形白勾确认钮**;0 选点确认=退出选择模式
- 行首选圈(选中蓝底白勾,行浅灰底);搜索框保留
- 底部:**标签栏隐藏**;左下功能图标组 + 右下圆点更多
  - 本地(常用目录/收件箱):分享(SF square.and.arrow.up)/ 删除(SF trash,红)
  - 远端(设备页):下载(square.and.arrow.down)/ 转发(square.and.arrow.up)
- 点确认 → 选设备弹层

### 4.3 选设备弹层(发送/转发确认后)
半屏 sheet:抓手+「发送 N 项到…」+取消(左);设备行同设备页语言;**在线可选、离线置灰不可选**;点设备即开始传输;下滑/遮罩关闭。

### 4.4 设备页
列表根:行=蓝 ›+设备图标(显示器/手机/终端)+名称+「平台 · 在线/最近时间」+右侧状态点(绿/灰)。点进=远端浏览(4.1 模板,标题=设备名→文件夹名)。

### 4.5 传输列表页
分段控件 全部/接收/发送/调度;行=类型徽章(接收蓝/发送绿/调度紫灰)+任务名+**方向设备**(如「公司台式机 → 本机」)+状态:进行中=细进度条+速度+百分比,中断=红字原因,完成=绿勾+时间;最新在最上;**左滑**:↻ 重新发起(中断/失败)/ 🗑 清除(终态);「···」=清除已完成;「N 项」沉底。

### 4.6 我的 / 登录 / 设置
- **我的**:左上扫码图标(占位"敬请期待")、右上齿轮;账号行(字母头像+邮箱+设备名·在线;未登录=一枚「登录」按钮);联系我们/为我打分/我的权益三个占位行(›);退出登录(红字行);版本号沉底
- **登录页**(推入):邮箱 → 验证码+「获取验证码」→ 蓝色大按钮「登录」;设备名默认主机名(iPhone)作注脚;「高级选项」小链接展开 服务器/CA(默认烤入 www.mtdss.top)
- **设置页**(推入):我的设备名(默认主机名,点入改)/ 显示隐藏项(iOS 开关,默认关)/ **信任目录**(已授权列表+移除;「添加…」开系统目录选择器即授权;小节注明"收件箱默认可见,无需添加")

### 4.7 分享扩展(方案 A,2026-10-31 定稿)
从相册/文件 App「分享 → MTDSS」弹半屏确认页:App 图标+「发送到 MTDSS」+项目清单+**缓存设备列表**(主 App 定期写入 App Group;离线置灰)。**点设备 = 文件+目标一起排队 + 自动拉起主 App 接发**(打开时任务已在传)。扩展不跑引擎。
> 系统约束:iOS 分享扩展拉起宿主 App 有官方限制,存在通行绕法(responder chain)但带审核风险——实现时先验证 `NSExtensionContext.open` 在 iOS 26 的实际行为,绕法作备选并评估;若均不可行,降级为「已排队,打开 App 即自动发送」。

**队列工程与失败语义(builder 评审 #4 补)**:扩展拷贝入 App Group 按 P4a 同款两步(临时名+完成 rename),队列项记录入队时 size,主 App 消费时校验;**拷一半被杀/校验不过的队列项不静默丢弃**——主 App 下次启动在传输列表生成失败态条目(「分享转交失败」),用户可重试(记录人裁定,数据丢失形状的意外不可接受);设备缓存仅主 App 前台期间写入,扩展读到陈旧缓存按离线置灰兜底。

## 5. 工程架构

### 5.1 引擎进进程(与安卓路线的唯一变形点)
iOS 禁止 App 创建子进程 → 安卓「mtdssd 子进程+UDS」不可平移。形态:
- mtdssd 编为**静态库**(aarch64-apple-ios)链进主 App,App 启动即在**进程内线程**跑引擎主循环,监听同进程 Unix domain socket
- lib 契约(builder 评审 #3 修):C 面三件套 `mtdss_ios_start` / `mtdss_ios_stop` / `mtdss_ios_ipc_path`;bin 的 prelude(rustls provider 安装、init_tracing、settings/recv_dir 解析)迁入 lib 入口属 lib 化授权范围(非"零改动"红线,桌面 bin 行为不变)
- Swift 侧监督:hello 心跳失败→进程内重启引擎线程,连续失败升级错误横幅(授权 builder 定细节)——iOS 无进程隔离,安卓"子进程死=可检测重启"的语义由此面承接
- Swift 是 `crates/ipc` 契约的**又一客户端**(与 Kotlin 同款打法):ipc JSON over UDS;**golden JSON 双端防漂移**直接复用(安卓 51 文件锁定 → iOS 对齐)

### 5.2 文件系统
- 沙箱直通:文件三原语(open_source/create_dest/ls_source)在 iOS 走 std::fs 桌面退化路径(无 SAF 层)
- 收件箱=App Documents(UIFileSharingEnabled+LSSupportsOpeningDocumentsInPlace → 文件 App「我的 iPhone/MTDSS」可见)
- 信任目录=UIDocumentPickerViewController 选目录 → **安全域书签**(security-scoped bookmark)持久化,引擎经书签解析访问
- 收件暂存=App 私有 `.mtdss` 隐藏目录(对文件 App 不可见),完成发布两步 move+rename(P4a 语义;r2 教训:rename 不跨目录须同目录两步)

### 5.3 进程与生命周期
- 前台=在线:App 挂起即引擎断线,任务标中断(不额外做 beginBackgroundTask 续命——安卓同款语义,预期内)
- 任务持久化在引擎侧(tasks.json 原子写),App 重启恢复列表(P2)

### 5.4 Share Extension
- 独立 target `top.mtdss.ios.share`,**不链引擎**(扩展内存限额+秒级寿命,系统硬限制)
- App Group `group.top.mtdss.shared`:①转交队列(扩展把分享文件拷入共享容器+写 job 意图含目标设备)②设备列表缓存(主 App 定期写入)
- 主 App 启动/回前台时消化队列:文件转正式发送(引擎接管),清队列
- 拉起宿主:见 4.7 风险注

### 5.5 身份与签名
- bundle ID `top.mtdss.ios`(个人账号;公开上架若介意卖家名显示个人姓名,后续转公司账号可迁移)
- 开发+发布证书/描述文件经 App Store Connect;TestFlight 外部组(个人号无内部团队席位;每版本首构建过轻量 Beta 审核)
- 传输中 FLAG_KEEP_SCREEN_ON 对应 iOS `isIdleTimerDisabled`

### 5.6 权限
- **本地网络权限(必备,2026-10-31 builder 评审补)**:引擎直连优先 RFC1918 私网候选(同 Wi-Fi PC↔iPhone 是旗舰场景),iOS 14+ 对本地网络单播连接强制 `NSLocalNetworkUsageDescription`,缺失时**系统不弹窗、静默断连**。Info.plist 必带,文案(记录人拟,用户可否):「MTDSS 需要在本地网络中查找并连接你的其他设备,以实现高速直连传输。」
- 通知权限(本地通知)弹一次;沙箱+书签授权模型无其他特殊权限(毙 MANAGE_EXTERNAL_STORAGE 的 iOS 同理)。

## 6. 开发环境与分工

- **Windows(本机)= 主战**:仓库、引擎 Rust 面、契约/golden、计划与评审、CI 配置——工作方式不变
- **Mac mini = 构建盒**(与 Windows 网络不通,经 VPS 桥):
  - 一次性物理安装(用户远程桌面):系统/Xcode/Rust iOS 工具链/cargo;开"断电自动重启"
  - 通道:autossh 反向隧道 `autossh -R 2222:localhost:22 <vps>`(VPS 已有 sshd,零新增服务,默认只绑 VPS localhost 不暴露公网);备选 frp(VPS 部署)/Tailscale(国内打洞看运气)
  - Claude 经 SSH 驱动:`cargo build --target aarch64-apple-ios`、`xcodebuild`、`swift test`、`xcrun simctl`(截图回拉代替开屏);VPS sshd 偶发 Connection reset → keepalive+重试
- **真机**:iPhone 12(iOS 26.5.2,地板)+ iPhone 16 Pro Max(iOS 27.2,天花板),TestFlight 分发(手机不在 Mac 边上也能装)
- **CI**:GitHub Actions macOS runner 兜底(android job 先例):iOS job=引擎编译+swift test+golden 校验;归档/签名后续进 CI
- 最低支持:**iOS 26.0**(iPhone 12 即地板设备;无旧系统降级妥协,直接用 Liquid Glass 时代 API)

## 7. 测试策略

1. **宿主单测+golden**:`swift test`(Mac mini/CI,不开模拟器)——契约面大头,Kotlin 257 例经验平移
2. **模拟器日常**(Mac mini,simctl 无人值守):UI 布局/主流程/**与 PC 真互传 E2E**(模拟器跑完整网络栈,连 VPS 信令与 Windows 对端实传)
3. **真机定案**(TestFlight):杀后台语义(P5 版 F3 猎杀)、蜂窝触发中继、收件暂存/发布、性能
4. 每轮冒烟 checklist 落 `docs/smoke-p5.md`(对齐 smoke-p3/p4a 体例)

## 8. 里程碑(供计划拆解,非承诺)

1. **M0 基建**:Mac mini 隧道打通+工具链验证(第一个 iOS target cargo build 过)+Xcode 工程骨架+CI iOS job
2. **M1 引擎进进程**:daemon lib 化+UDS in-process+Swift ipc 客户端+golden 双端绿;模拟器登录/在线
3. **M2 核心流**:浏览模板全套(浏览/选择/搜索/排序)+设备页+发送/下载/转发链
4. **M3 收件与任务**:收件箱+暂存发布+传输列表(左滑/重发)+本地通知
5. **M4 我的/登录/设置**+信任目录书签
6. **M5 分享扩展**(App Group 队列+拉起验证)+打磨+TestFlight 首版

## 9. 风险与开放问题
