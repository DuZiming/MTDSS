# MTDSS V2-P5 iOS 客户端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 MTDSS iOS 客户端 v1(功能对齐安卓 v1,TestFlight 内测),引擎以静态库进 App 进程复用,UI 按 2026-10-31 定稿的"文件 App 范式"。

**Architecture:** `crates/daemon` 已是 lib+bin;新增 `crates/ios-bridge`(staticlib,唯一 C 启动函数)链入 App,进程内线程跑引擎、同进程 UDS 上沿用 ipc NDJSON 契约。Swift 侧新建顶层 `ios/`(与 `android/` 对等):SwiftPM 包 `MTDSSKit`(契约/IpcClient/Repository/黄金测试,宿主 `swift test`)+ xcodegen 生成的 App 与 Share Extension 双 target。分享扩展不链引擎,经 App Group 队列转交。

**Tech Stack:** Rust(workspace 既有)/ Swift 6 + SwiftUI / SwiftPM / xcodegen / Xcode 26 / TestFlight。不新增重依赖。

**Spec:** docs/superpowers/specs/2026-10-31-mtdss-v2p5-ios-design.md(本计划据其论证,执行者两份都读)

## Global Constraints

- 最低 iOS 26.0;iPhone-only 竖屏;测试机 iPhone 12@26.5.2(地板)+ iPhone 16 Pro Max@27.2
- bundle ID `top.mtdss.ios`;Share Extension `top.mtdss.ios.share`;App Group `group.top.mtdss.shared`
- `crates/ipc/contract/*.json` 是契约单一真源,只读消费;`crates/proto`、`crates/ipc` 协议面**零改动**(发现缺口→停,回spec)
- Windows 侧 `cargo check --workspace` 在任何任务后必须保持绿(桌面线不许被 iOS 线弄红)
- daemon 桌面专属模块门禁从 `not(android)` 收敛为 `not(any(android, ios))`:tray/uilaunch/notify;update 已是 windows-only 不动
- UI 逐屏对表 spec §4(含推翻记录 §4.8——**不许**按早期卡片/彩砖 mockup 施工);中文文案
- 引擎构建锁定命令:`cargo build -p ios-bridge --target aarch64-apple-ios --release`(对应安卓的 cargo-ndk 锁定命令先例)
- mockup 存档仅作视觉参考:`.superpowers/brainstorm/36819-1793396074/content/`

## Review Focus

1. **引擎线程 panic 杀整个 App**(安卓有进程隔离,iOS 没有)——T2 桥接层 catch_unwind 包裹,panic 转 stderr+事件帧,App 不死;测试:桥内 panic 注入单测。
2. **golden 漂移**(Swift 序列化与 Rust 端不一致)——T3 黄金套件逐字节比对全量 `contract/*.json`;daemon 契约测试同源已在 CI。
3. **切后台传输中断的态**(挂起→socket 断→任务标「中断」,重开 App 手动重发成功)——T10/T6 冒烟钉死(模拟器切后台可复现)。
4. **收件暂存中间态在文件 App 可见**(违反"完成后才发布")——T9 验证:传输中查文件 App 无 `.part` 残留、杀 App 后仅 `.mtdss` 私有区有件;完成后顶层本名出现。
5. **App 容器路径随重装变化**(UDS 路径/收件箱绝对路径写死即崩)——T4/T9 全部路径经 `home` 动态解析,禁字面;测试:golden 不含绝对路径 + 单测路径派生。
