# MTDSS M1（骨架贯通）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 打通最小垂直切片：信令服务器（账号/设备/信令转发）+ 两个 CLI 经服务器信令发现彼此、在局域网/本机建立带证书固定的 QUIC 直连、完成单个文件的分块校验传输。

**Architecture:** Cargo workspace，四个成员：`mtdss-proto`（protobuf 定义）、`mtdss-core`（身份/信令客户端/QUIC 传输/清单，零 UI 依赖）、`mtdss-cli`（无头客户端）、`signaling` 服务器（axum lib+bin，SQLite）。信令载荷端到端加密（crypto_box + Ed25519 签名），QUIC 双向设备证书固定（SPKI 比对）。

**Tech Stack:** Rust stable；quinn 0.11 (rustls/ring)、rustls 0.23、rcgen 0.13、ed25519-dalek 2 (pkcs8)、crypto_box 0.8、prost 0.13、axum 0.8 (ws)、rusqlite 0.32 (bundled)、jsonwebtoken 9、tokio 1、tokio-tungstenite 0.24、if-addrs 0.13、x509-parser 0.16、clap 4.5 (derive)、sha2 0.10、dashmap 6。

**Spec:** `docs/superpowers/specs/2026-10-15-mtdss-v1-design.md`（本计划从该规范推导，执行者须同时阅读规范与本计划）

**范围：** 仅 M1。单文件（不含目录/多文件/断点续传/STUN/打洞——M2）、无 daemon/UI（M3）、无打包签名（M4）。本机/局域网候选地址直连。

## Global Constraints

- 工具链：`rust-toolchain.toml` 固定 stable 频道；Windows 为主开发环境，代码必须保持三平台可编译（只用 `std::path`，无 unix-only 调用）。
- 依赖版本：以上列出的 caret 下限在写作时验证兼容；若实现时 minor 版本 API 漂移，允许适配，**但必须保持任务测试锁定的行为/安全属性不变**（如双向 SPKI 固定、信令端到端加密）。
- 每个任务结束时 `cargo test --workspace` 与 `cargo clippy --workspace -- -D warnings` 必须全绿；提交信息用 Conventional Commits（`feat:`/`test:`/`chore:`/`docs:`）。
- 永不记录密钥材料与文件内容：日志（tracing）只允许出现 device_id、地址、错误类别。
- 设备 ID 规则（全项目统一）：`device_id = hex(sha256(ed25519_public_key_bytes))[0..32]`（32 个十六进制字符）。
- Ed25519 自签证书的 SubjectPublicKeyInfo DER 前缀固定为 `302a300506032b6570032100` + 32 字节公钥（QUIC 固定验证依赖此事实）。
- 所有网络等待必须带超时（信令等待 10s，QUIC 空闲断开 30s）。
- CLI 是内部开发工具，输出用英文；面向用户的文案（V1 中文）属于 M3 UI。
- 规范偏离记录：设计文档 §4.3 的"服务器不可中间人"依赖公钥可信分发。M1 采用 TOFU（发送方本地缓存对端公钥 `peers.json`，变更即硬错误），残余风险（服务器在双方首次接触前主动替换公钥）与对策（带外安全码校验）记入规范开放项，由 M3 的配对 UI 解决。本计划 Task 12 实现缓存与变更检测。

## Review Focus

规范隐含但无任务测试覆盖、最可能咬到真实用户的五类输入（每条已把测试加入所属任务）：

1. **0 字节文件与磁盘预检**：0 字节文件（清单零分块）必须成功传输；接收盘剩余空间小于文件总大小时必须在接受前拒绝——测试在 Task 10（零分块清单）与 Task 11（磁盘预检拒绝）。
2. **manifest 相对路径穿越**：`rel_path` 含 `..`、绝对路径、反斜杠时接收方必须拒绝（安全）——测试在 Task 10（`validate_rel_path`）与 Task 11（接收侧再验）。
3. **同名并发传输的 .part 冲突**：两个传输写同一输出文件名互不踩踏（`.part` 以 transfer_id 命名隔离）——测试在 Task 11。
4. **Unicode 文件名**：CJK/emoji 文件名与 Windows 路径分隔符（`/` 归一化）——测试在 Task 10/11。
5. **信令超时与对端离线**：等待 ConnectAccept/Candidates 超时、向离线设备发 Relay 得到明确错误而非挂死——测试在 Task 6（离线 relay 错误）与 Task 12（10s 超时路径）。

```protobuf
syntax = "proto3";
package mtdss.ws;

// 设备 -> 服务器（WebSocket 二进制帧）
message WsClientFrame {
  oneof frame {
    Hello hello = 1;        // 必须是连接后第一帧
    Relay relay = 2;        // 请转发给 to_device
  }
}

// 服务器 -> 设备
message WsServerFrame {
  oneof frame {
    HelloOk hello_ok = 1;
    Error error = 2;        // 错误码：1=认证失败 2=目标不在线 3=负载非法
    Relayed relayed = 3;    // 来自 from_device 的转发
    Presence presence = 4;  // 同账号设备上下线
  }
}

message Hello { string device_id = 1; string jwt = 2; }
message HelloOk { string account_id = 1; }
message Error { uint32 code = 1; string message = 2; }
message Relay { string to_device = 1; bytes payload = 2; }
message Relayed { string from_device = 1; bytes payload = 2; }
message Presence { string device_id = 1; bool online = 2; }
```

- [ ] **Step 3: 实现 identity.rs**

```rust
use anyhow::{Context, Result};
use ed25519_dalek::{Signer, Signature, SigningKey, VerifyingKey};
use rand::RngCore;
use sha2::{Digest, Sha256};
use std::path::Path;

/// Ed25519 SubjectPublicKeyInfo DER：12 字节头 + 32 字节密钥
pub const ED25519_SPKI_PREFIX: [u8; 12] =
    [0x30, 0x2a, 0x30, 0x05, 0x06, 0x03, 0x2b, 0x65, 0x70, 0x03, 0x21, 0x00];

pub fn spki_ed25519(pk: &VerifyingKey) -> [u8; 44] {
    let mut out = [0u8; 44];
    out[..12].copy_from_slice(&ED25519_SPKI_PREFIX);
    out[12..].copy_from_slice(pk.as_bytes());
    out
}

pub fn device_id_for(pk: &VerifyingKey) -> String {
    let mut h = Sha256::new();
    h.update(pk.as_bytes());
    hex::encode(h.finalize())[..32].to_string()
}

pub struct DeviceIdentity {
    pub device_id: String,
    pub signing: SigningKey,
    cert_cache: std::sync::OnceLock<Vec<u8>>,
}

impl DeviceIdentity {
    pub fn generate() -> Self {
        let mut seed = [0u8; 32];
        rand::thread_rng().fill_bytes(&mut seed);
        Self::from_seed(&seed)
    }

    pub fn from_seed(seed: &[u8; 32]) -> Self {
        let signing = SigningKey::from_bytes(seed);
        let device_id = device_id_for(&signing.verifying_key());
        Self { device_id, signing, cert_cache: std::sync::OnceLock::new() }
    }

    pub fn from_seed_file(path: &Path) -> Result<Self> {
        let text = std::fs::read_to_string(path)
            .with_context(|| format!("read seed {}", path.display()))?;
        let hexs = text.trim();
        let bytes = hex::decode(hexs).context("seed file is not hex")?;
        let seed: [u8; 32] = bytes.as_slice().try_into().map_err(|_| anyhow::anyhow!("seed must be 32 bytes"))?;
        Ok(Self::from_seed(&seed))
    }

    pub fn save_seed(&self, path: &Path) -> Result<()> {
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::write(path, hex::encode(self.signing.to_bytes()))?;
        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;
            let _ = std::fs::set_permissions(path, std::fs::Permissions::from_mode(0o600));
        }
        Ok(())
    }

    pub fn public_key(&self) -> VerifyingKey {
        self.signing.verifying_key()
    }

    pub fn sign(&self, msg: &[u8]) -> Signature {
        self.signing.sign(msg)
    }

    /// Ed25519 自签证书（der），同一身份稳定
    pub fn cert_der(&self) -> Vec<u8> {
        self.cert_cache.get_or_init(|| self.build_cert()).clone()
    }

    fn build_cert(&self) -> Vec<u8> {
        use rcgen::{CertificateParams, KeyPair, PKCS_ED25519};
        let pkcs8 = self.signing.to_pkcs8v1_der();
        let kp = KeyPair::from_pkcs8_der_and_sign_algo(
            &pkcs8.as_bytes().into(),
            &PKCS_ED25519,
        ).expect("ed25519 keypair -> rcgen");
        let mut params = CertificateParams::new(vec!["mtdss-device".to_string()])
            .expect("cert params");
        params.serial_number = Some(rcgen::SerialNumber::from(42));
        // 固定有效期窗口起始于 epoch，保证 DER 稳定
        params.not_before = time::OffsetDateTime::UNIX_EPOCH;
        params.not_after = time::OffsetDateTime::from_unix_timestamp(253402300799).unwrap();
        let cert = params.self_signed(&kp).expect("self-signed cert");
        cert.der().to_vec()
    }
}
```

```rust
use crate::AppState;
use anyhow::{anyhow, Result};

use serde::{Deserialize, Serialize};
use sha2::{Digest, Sha256};
use std::sync::Arc;

#[derive(Serialize, Deserialize)]
pub struct Claims {
    pub sub: String,   // account_id
    pub device: String,
    pub exp: usize,
    pub typ: String,   // "access" | "refresh"

pub struct VerifyOk {
    pub account_id: String,
    pub device_id: String,
    pub jwt: String,
    pub refresh: String,

const CODE_TTL_SECS: i64 = 600;

pub fn request_code(state: &AppState, email: &str) -> Result<String> {
    let code = format!("{:06}", rand::thread_rng().next_u64() % 1_000_000);
    let mut h = Sha256::new();
    h.update(code.as_bytes());
    let conn = state.db.lock().unwrap();
    conn.execute(
        "DELETE FROM codes WHERE email=?1",
        rusqlite::params![email],
    )?;
    conn.execute(
        "INSERT INTO codes(email, code_hash, expires_at) VALUES(?1,?2,?3)",
        rusqlite::params![email, hex::encode(h.finalize()), now() + CODE_TTL_SECS],
    )?;
    tracing::info!(email = %email, "verification code issued (dev mode returns it)");
    Ok(code)
}

pub fn verify_code(
    state: &AppState,
    email: &str,
    code: &str,
    pubkey_hex: &str,
    name: &str,
    platform: &str,
) -> Result<VerifyOk> {
    let mut h = Sha256::new();
    h.update(code.as_bytes());
    let conn = state.db.lock().unwrap();
    let ok: bool = conn
        .query_row(
            "SELECT expires_at > ?3 FROM codes WHERE email=?1 AND code_hash=?2",
            rusqlite::params![email, hex::encode(h.finalize()), now()],
            |r| r.get(0),
        )
        .unwrap_or(false);
    if !ok {
        return Err(anyhow!("invalid or expired code"));
    }
    conn.execute("DELETE FROM codes WHERE email=?1", rusqlite::params![email])?;

    let account_id: String = match conn
        .query_row("SELECT id FROM accounts WHERE email=?1", [email], |r| r.get(0))
    {
        Ok(id) => id,
        Err(_) => {
            let id = hex::encode(rand::random::<[u8; 16]>());
            conn.execute(
                "INSERT INTO accounts(id, email, created_at) VALUES(?1,?2,?3)",
                rusqlite::params![id, email, now()],
            )?;
            id
        }
    };

    let pk_bytes = hex::decode(pubkey_hex)?;
    let pk: VerifyingKey = VerifyingKey::from_bytes(&pk_bytes.try_into().map_err(|_| anyhow!("pubkey must be 32 bytes"))?)?;
    let device_id = hex::encode(Sha256::digest(pk.as_bytes()))[..32].to_string();
    conn.execute(
        "INSERT INTO devices(account_id, device_id, pubkey, name, platform, created_at)
         VALUES(?1,?2,?3,?4,?5,?6)
         ON CONFLICT(device_id) DO UPDATE SET name=?4, platform=?5",
        rusqlite::params![account_id, device_id, pubkey_hex, name, platform, now()],
    )?;
    drop(conn);

    let jwt = mint_access_jwt(&state.jwt_secret, &account_id, &device_id);
    let refresh = mint_refresh_jwt(&state.jwt_secret, &account_id, &device_id);
    Ok(VerifyOk { account_id, device_id, jwt, refresh })
}

pub fn mint_access_jwt(secret: &[u8; 32], account_id: &str, device_id: &str) -> String {
    mint(secret, account_id, device_id, "access", 60 * 60 * 24)
}
pub fn mint_refresh_jwt(secret: &[u8; 32], account_id: &str, device_id: &str) -> String {
    mint(secret, account_id, device_id, "refresh", 60 * 60 * 24 * 30)
}
fn mint(secret: &[u8; 32], account_id: &str, device_id: &str, typ: &str, ttl: usize) -> String {
    let c = Claims {
        sub: account_id.into(),
        device: device_id.into(),
        exp: (std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .unwrap()
            .as_secs() as usize)
            + ttl,
        typ: typ.into(),
    };
    encode(&Header::default(), &c, &EncodingKey::from_secret(secret)).unwrap()
}

pub fn verify_jwt(secret: &[u8; 32], token: &str) -> Result<Claims> {
    let data = decode::<Claims>(
        token,
        &DecodingKey::from_secret(secret),
        &Validation::default(),
    )?;
    Ok(data.claims)
}

pub fn rotate_refresh(state: &AppState, refresh: &str) -> Result<VerifyOk> {
    let c = verify_jwt(&state.jwt_secret, refresh)?;
    if c.typ != "refresh" {
        return Err(anyhow!("not a refresh token"));
    }
    let conn = state.db.lock().unwrap();
    let device_id = c.device.clone();
    let (account_id, pubkey_hex): (String, String) = conn.query_row(
        "SELECT account_id, pubkey FROM devices WHERE device_id=?1",
        [&device_id],
        |r| Ok((r.get(0)?, r.get(1)?)),
    )?;
    drop(conn);
    Ok(VerifyOk {
        account_id,
        device_id,
        jwt: mint_access_jwt(&state.jwt_secret, &c.sub, &device_id),
        refresh: mint_refresh_jwt(&state.jwt_secret, &c.sub, &device_id),
        _pubkey: pubkey_hex,
    })
}
```

```rust
    let jwt = headers
        .get("authorization")
        .and_then(|v| v.to_str().ok())
        .and_then(|v| v.strip_prefix("Bearer "))
        .ok_or((StatusCode::UNAUTHORIZED, "missing bearer".into()))?;

    }
    let conn = state.db.lock().unwrap();
    let mut stmt = conn
        .prepare("SELECT device_id, name, platform, pubkey FROM devices WHERE account_id=?1")
        .map_err(|e| (StatusCode::INTERNAL_SERVER_ERROR, e.to_string()))?;
    let devices: Vec<DeviceInfo> = stmt
        .query_map([&claims.sub], |r| {
            Ok(DeviceInfo {
                device_id: r.get(0)?,
                name: r.get(1)?,
                platform: r.get(2)?,
                pubkey: r.get(3)?,
            })
        })
        .map_err(|e| (StatusCode::INTERNAL_SERVER_ERROR, e.to_string()))?
        .filter_map(|r| r.ok())
        .map(|d| DeviceInfo { online: state.presence.is_online(&d.device_id), ..d })
        .collect();

    Ok(Json(serde_json::json!({ "devices": devices })))
```

```rust
        tokio_tungstenite::MaybeTlsStream<tokio::net::TcpStream>>,

            other => panic!("unexpected {other:?}"),

    }
```

```rust
use crate::AppState;
use axum::extract::ws::{Message, WebSocket, WebSocketUpgrade};
use axum::extract::State;
use futures_util::{SinkExt, StreamExt};
use mtdss_proto::ws::*;
use prost::Message as _;
use std::sync::Arc;

#[derive(Clone)]
pub struct PeerHandle {
    pub account_id: String,
    pub tx: tokio::sync::mpsc::Sender<Message>,
}

pub async fn ws_handler(
    State(state): State<Arc<AppState>>,
    ws: WebSocketUpgrade,
) -> axum::response::Response {
    ws.on_upgrade(move |socket| handle_socket(state, socket))
}

async fn handle_socket(state: Arc<AppState>, socket: WebSocket) {
    let (mut sink, mut stream) = socket.split();
    // 1) 第一帧必须是合法 Hello
    let first = tokio::time::timeout(std::time::Duration::from_secs(10), stream.next()).await;
    let Some(Ok(Ok(msg))) = first else { return };
    let Ok(bin) = msg.into_binary() else { return };
    let Ok(frame) = WsClientFrame::decode(bin.as_ref()) else { return };
    let Some(ws_client_frame::Frame::Hello(h)) = frame.frame else {
        let _ = sink.send(err(1, "first frame must be hello")).await;
        return;
    };
    let claims = match crate::auth::verify_jwt(&state.jwt_secret, &h.jwt)
        .map_err(|_| ())

    {
        Ok(c) if c.typ == "access" => c,
        _ => {
            let _ = sink.send(err(1, "bad jwt")).await;
            return;
        }
    };
    // 2) device_id 必须属于该账号且公钥哈希一致（防冒用他人 device_id）
    let owner: Option<String> = {
        let conn = state.db.lock().unwrap();
        conn.query_row(
            "SELECT account_id FROM devices WHERE device_id=?1",
            [&h.device_id],
            |r| r.get(0),
        )
        .ok()
    };
    if owner.as_deref() != Some(claims.sub.as_str()) || claims.device != h.device_id {
        let _ = sink.send(err(1, "device not bound to account")).await;
        return;
    }
    let account_id = claims.sub.clone();
    let device_id = h.device_id.clone();

    // 3) 进入在线态：注册 presence + 广播给同账号
    let (tx, mut rx) = tokio::sync::mpsc::channel::<Message>(64);
    state.presence.insert(&device_id, PeerHandle { account_id: account_id.clone(), tx });
    broadcast_presence(&state, &account_id, &device_id, true);
    let ok = WsServerFrame { frame: Some(ws_server_frame::Frame::HelloOk(ws::HelloOk {
        account_id: account_id.clone() })) };
    let _ = sink.send(Message::Binary(ok.encode_to_vec().into())).await;

    // 4) 主循环：转发退出消息 + 处理入站
    let mut sink_opt = Some(sink);
    loop {
        tokio::select! {
            out = rx.recv() => match (out, sink_opt.as_mut()) {
                (Some(m), Some(s)) => { if s.send(m).await.is_err() { break; } }
                _ => break,
            },
            inbound = stream.next() => {
                let Some(Ok(msg)) = inbound else { break };
                let Ok(bin) = msg.into_binary() else { continue };
                let Ok(f) = WsClientFrame::decode(bin.as_ref()) else {
                    if let Some(s) = sink_opt.as_mut() {
                        let _ = s.send(err(3, "bad frame")).await;
                    }
                    break;
                };
                match f.frame {
                    Some(ws_client_frame::Frame::Relay(r)) => {
                        let result = state.relay(&device_id, &account_id, &r.to_device, &r.payload);
                        if let Some(e) = result.err() {
                            if let Some(s) = sink_opt.as_mut() {
                                let _ = s.send(err(e.0, e.1)).await;
                            }
                        }
                    }
                    _ => {
                        if let Some(s) = sink_opt.as_mut() {
                            let _ = s.send(err(3, "expected relay")).await;
                        }
                    }
                }
            }
        }
    }
    // 5) 离线：清理 + 广播
    state.presence.remove(&device_id);
    broadcast_presence(&state, &account_id, &device_id, false);
}

fn err(code: u32, msg: &str) -> Message {
    Message::Binary(WsServerFrame {
        frame: Some(ws_server_frame::Frame::Error(ws::Error { code, message: msg.into() })),
    }.encode_to_vec().into())
}

fn broadcast_presence(state: &AppState, account_id: &str, device_id: &str, online: bool) {
    let msg = Message::Binary(WsServerFrame {
        frame: Some(ws_server_frame::Frame::Presence(ws::Presence {
            device_id: device_id.into(), online })) }.encode_to_vec().into());
    for entry in state.presence.account_peers(account_id) {
        if entry.key() != device_id {
            let _ = entry.tx().try_send(msg.clone());
        }
    }
}
```

```rust
    pub fn relay(&self, from: &str, from_account: &str, to: &str, payload: &[u8])
        -> Result<(), (u32, String)>
```

```rust
use crate::identity::DeviceIdentity;
use ed25519_dalek::Verifier;
use mtdss_proto::signal::*;
use prost::Message;
use thiserror::Error;

#[derive(Debug, PartialEq, Clone)]
pub enum SignalBody {
    ConnectRequest { session_id: Vec<u8> },
    ConnectAccept { session_id: Vec<u8> },
    Candidates { session_id: Vec<u8>, addrs: Vec<String> },
}

#[derive(Debug, Error)]
pub enum EnvelopeError {
    #[error("decode failed")] Decode,
    #[error("cannot open sealed box")] Open,
    #[error("sender signature invalid")] Signature,
    #[error("payload malformed")] Malformed,
}

fn body_to_proto(b: &SignalBody) -> signal_body::Body {
    match b {
        SignalBody::ConnectRequest { session_id } =>
            signal_body::Body::ConnectRequest(ConnectRequest { session_id: session_id.clone() }),
        SignalBody::ConnectAccept { session_id } =>
            signal_body::Body::ConnectAccept(ConnectAccept { session_id: session_id.clone() }),
        SignalBody::Candidates { session_id, addrs } =>
            signal_body::Body::Candidates(Candidates { session_id: session_id.clone(), addrs: addrs.clone() }),
    }
}

fn body_from_proto(b: &signal_body::Body) -> Result<SignalBody, EnvelopeError> {
    Ok(match b {
        signal_body::Body::ConnectRequest(m) => SignalBody::ConnectRequest { session_id: m.session_id.clone() },
        signal_body::Body::ConnectAccept(m) => SignalBody::ConnectAccept { session_id: m.session_id.clone() },
        signal_body::Body::Candidates(m) => SignalBody::Candidates { session_id: m.session_id.clone(), addrs: m.addrs.clone() },
    })
}

/// signal.proto 的 SignalPayload 需带 oneof body：见下方 mod 扩展说明。
/// （SignalPayload 在 proto 中定义为 { bytes sig; bytes body; }，body 为内层
///  `Body` oneof 消息 `signal_body` 的编码字节。）

pub fn seal(
    sender: &DeviceIdentity,
    recipient: &ed25519_dalek::VerifyingKey,
    body: &SignalBody,
) -> Vec<u8> {
    let inner = signal_body::BodyProto { body: Some(body_to_proto(body)) }.encode_to_vec();
    let sig = sender.sign(&inner);
    let payload = SignalPayload { sig: sig.to_bytes().to_vec(), body: inner };
    let sealed = crypto_box::seal(&recipient.into(), &payload.encode_to_vec());
    SignalEnvelope {
        sender_device_id: sender.device_id.clone(),
        sealed: sealed.to_vec(),
    }
    .encode_to_vec()
}

pub fn open(
    data: &[u8],
    me: &DeviceIdentity,
    sender_pk: &ed25519_dalek::VerifyingKey,
) -> Result<SignalBody, EnvelopeError> {
    let env = SignalEnvelope::decode(data).map_err(|_| EnvelopeError::Decode)?;
    let my_pk: crypto_box::PublicKey = (&me.public_key()).into();
    let my_sk: crypto_box::SecretKey = (&me.signing).into();
    let plain = crypto_box::open(&my_sk, &my_pk, env.sealed.as_slice().into())
        .map_err(|_| EnvelopeError::Open)?;
    let payload = SignalPayload::decode(plain.as_slice()).map_err(|_| EnvelopeError::Malformed)?;
    let sig = ed25519_dalek::Signature::from_slice(&payload.sig)
        .map_err(|_| EnvelopeError::Signature)?;
    sender_pk.verify(&payload.body, &sig).map_err(|_| EnvelopeError::Signature)?;
    let inner = signal_body::BodyProto::decode(payload.body.as_slice())
        .map_err(|_| EnvelopeError::Malformed)?;
    body_from_proto(&inner.body.ok_or(EnvelopeError::Malformed)?)
}
```

```rust
use anyhow::{Context, Result};
use futures_util::{SinkExt, StreamExt};
use mtdss_proto::ws::*;
use prost::Message as _;
use tokio::sync::mpsc;
use tokio_tungstenite::tungstenite::Message as WsMessage;

#[derive(Debug)]
pub enum ClientEvent {
    Relayed { from: String, payload: Vec<u8> },
    Presence { device_id: String, online: bool },
    Error { code: u32, message: String },
    Closed,
}

#[derive(Clone)]
pub struct SignalingClient {
    tx: mpsc::Sender<Vec<u8>>,
}

impl SignalingClient {
    pub async fn connect(
        url: &str,
        jwt: &str,
        device_id: &str,
    ) -> Result<(Self, mpsc::Receiver<ClientEvent>)> {
        let (ws, _resp) = tokio_tungstenite::connect_async(url)
            .await
            .context("connect signaling ws")?;
        let (mut sink, mut stream) = ws.split();

        let hello = WsClientFrame {
            frame: Some(ws_client_frame::Frame::Hello(Hello {
                device_id: device_id.into(), jwt: jwt.into() })) };
        sink.send(WsMessage::Binary(hello.encode_to_vec().into())).await?;

        let (ev_tx, ev_rx) = mpsc::channel(64);
        let (cmd_tx, mut cmd_rx) = mpsc::channel::<Vec<u8>>(64);

        tokio::spawn(async move {
            loop {
                tokio::select! {
                    cmd = cmd_rx.recv() => match cmd {
                        Some(bytes) =>
                            if sink.send(WsMessage::Binary(bytes.into())).await.is_err() { break; },
                        None => break,
                    },
                    inbound = stream.next() => match inbound {
                        Some(Ok(msg)) => {
                            let Ok(bin) = msg.into_binary() else { continue };
                            let Ok(f) = WsServerFrame::decode(bin.as_ref()) else { continue };
                            let ev = match f.frame {
                                Some(ws_server_frame::Frame::HelloOk(_)) => continue,
                                Some(ws_server_frame::Frame::Relayed(r)) =>
                                    ClientEvent::Relayed { from: r.from_device, payload: r.payload },
                                Some(ws_server_frame::Frame::Presence(p)) =>
                                    ClientEvent::Presence { device_id: p.device_id, online: p.online },
                                Some(ws_server_frame::Frame::Error(e)) =>
                                    ClientEvent::Error { code: e.code, message: e.message },
                                None => continue,
                            };
                            if ev_tx.send(ev).await.is_err() { break; }
                        }
                        _ => {
                            let _ = ev_tx.send(ClientEvent::Closed).await;
                            break;
                        }
                    },
                }
            }
        });

        Ok((Self { tx: cmd_tx }, ev_rx))
    }

    pub async fn relay(&self, to_device: &str, payload: &[u8]) -> Result<()> {
        let f = WsClientFrame {
            frame: Some(ws_client_frame::Frame::Relay(ws::Relay {
                to_device: to_device.into(), payload: payload.to_vec() })) };
        self.tx.send(f.encode_to_vec()).await.context("signaling client gone")
    }
}
```

```rust
/// SPKI 前缀（12 字节）+ Ed25519 公钥（32 字节）= 44
pub fn spki_matches(cert: &CertificateDer, expected: &[u8; 44]) -> bool {
    let (_, parsed) = match x509_parser::parse_x509_certificate(cert.as_ref()) {
        Ok(p) => p,
        Err(_) => return false,
    };
    parsed.public_key().raw == expected
}

// ---------- 客户端侧：固定服务端证书 ----------
#[derive(Debug)]
struct PinnedServerVerifier {
    expected_spki: [u8; 44],
}

impl rustls::client::danger::ServerCertVerifier for PinnedServerVerifier {
    fn verify_server_cert(
        &self,
        end_entity: &CertificateDer<'_>,
        _intermediates: &[CertificateDer<'_>],
        _server_name: &ServerName<'_>,
        _ocsp_response: &[u8],
        _now: rustls::pki_types::UnixTime,
    ) -> Result<rustls::client::danger::ServerCertVerified, rustls::Error> {
        if spki_matches(end_entity, &self.expected_spki) {
            Ok(rustls::client::danger::ServerCertVerified::assertion())
        } else {
            Err(rustls::Error::InvalidCertificate(
                rustls::CertificateError::BadEncoding,
            ))
        }
    }
    fn verify_tls12_signature(
        &self, _message: &[u8], _cert: &CertificateDer<'_>, _dss: &rustls::DigitallySignedStruct,
    ) -> Result<rustls::client::danger::HandshakeSignatureValid, rustls::Error> {
        Err(rustls::Error::PeerMisbehaved(
            rustls::PeerMisbehaved::WrongSignatureType.into_message("tls1.2 disabled"),
        ))
    }
    fn verify_tls13_signature(
        &self, _message: &[u8], _cert: &CertificateDer<'_>, _dss: &rustls::DigitallySignedStruct,
    ) -> Result<rustls::client::danger::HandshakeSignatureValid, rustls::Error> {
        Ok(rustls::client::danger::HandshakeSignatureValid::assertion())
    }
    fn supported_verify_schemes(&self) -> Vec<rustls::SignatureScheme> {
        vec![rustls::SignatureScheme::ED25519]
    }
    fn requires_raw_public_keys(&self) -> bool { false }
}

// ---------- 服务端侧：校验客户端证书 ----------
#[derive(Debug)]
struct DeviceClientCertVerifier {
    allowed: HashMap<[u8; 44], String>, // spki -> device_id
}

impl rustls::server::danger::ClientCertVerifier for DeviceClientCertVerifier {
    fn root_hint_subjects(&self) -> &[rustls::DistinguishedName] { &[] }
    fn verify_client_cert(
        &self,
        end_entity: &CertificateDer<'_>,
        _intermediates: &[CertificateDer<'_>],
        _now: rustls::pki_types::UnixTime,
    ) -> Result<rustls::server::danger::ClientCertVerified, rustls::Error> {
        for (spki, _) in self.allowed.iter() {
            if spki_matches(end_entity, spki) {
                return Ok(rustls::server::danger::ClientCertVerified::assertion());
            }
        }
        Err(rustls::Error::InvalidCertificate(rustls::CertificateError::BadEncoding))
    }
    fn verify_tls12_signature(
        &self, _m: &[u8], _c: &CertificateDer<'_>, _d: &rustls::DigitallySignedStruct,
    ) -> Result<rustls::client::danger::HandshakeSignatureValid, rustls::Error> {
        Err(rustls::Error::General("tls1.2 disabled".into()))
    }
    fn verify_tls13_signature(
        &self, _m: &[u8], _c: &CertificateDer<'_>, _d: &rustls::DigitallySignedStruct,
    ) -> Result<rustls::client::danger::HandshakeSignatureValid, rustls::Error> {
        Ok(rustls::client::danger::HandshakeSignatureValid::assertion())
    }
    fn supported_verify_schemes(&self) -> Vec<rustls::SignatureScheme> {
        vec![rustls::SignatureScheme::ED25519]
    }
    fn requires_raw_public_keys(&self) -> bool { false }

fn client_config(me: &DeviceIdentity, peer: &ed25519_dalek::VerifyingKey) -> rustls::ClientConfig {
    let mut cfg = rustls::ClientConfig::builder_with_protocol_versions(&[&rustls::version::TLS13])
        .dangerous()
        .with_custom_certificate_verifier(Arc::new(PinnedServerVerifier {
            expected_spki: spki_ed25519(peer),
        }))
        .with_client_auth_cert(
            vec![CertificateDer::from(me.cert_der())],
            PrivateKeyDer::try_from(me.signing.to_pkcs8v1_der().as_bytes().to_vec())
                .expect("pkcs8"),
        )
        .expect("client auth cert");

fn server_config(me: &DeviceIdentity, allowed: &HashMap<String, ed25519_dalek::VerifyingKey>)
    -> Result<rustls::ServerConfig>
```

```rust
pub fn validate_rel_path(rel: &str) -> bool {
    if rel.is_empty() || rel.len() > 4096 || rel == "." {
        return false;
    }
    if rel.starts_with('/') || rel.contains('\\') || rel.contains(':') {
        return false;
    }
    for seg in rel.split('/') {
        if seg.is_empty() || seg == "." {
            return false;
        }
    }
    let mut depth: i64 = 0;
    for seg in rel.split('/') {
        if seg == ".." { depth -= 1; if depth < 0 { return false; } } else { depth += 1; }
    }
    depth > 0
}

pub fn signable_bytes(transfer_id: &str, files: &[FileEntry]) -> Vec<u8> {
    use prost::Message;
    // 确定性：transfer_id || 各条目（rel_path, size, sha256, chunk 哈希串接）
    let mut out = transfer_id.as_bytes().to_vec();
    for f in files {
        out.extend_from_slice(f.rel_path.as_bytes());
        out.extend_from_slice(&f.size.to_le_bytes());
        out.extend_from_slice(&f.sha256);
        for c in &f.chunks {
            out.extend_from_slice(&c.sha256);
        }
    }
    out
}

pub fn build_single(path: &Path, rel: &str, id: &DeviceIdentity) -> Result<Manifest> {
    anyhow::ensure!(validate_rel_path(rel), "invalid rel path");
    let mut file = std::fs::File::open(path).with_context(|| path.display().to_string())?;
    let size = file.metadata()?.len();

    let mut whole = Sha256::new();
    let mut chunks: Vec<ChunkDesc> = Vec::new();
    let mut buf = vec![0u8; CHUNK_SIZE];
    let mut offset: u64 = 0;
    loop {
        let n = read_full(&mut file, &mut buf)?;
        if n == 0 { break; }
        let mut ch = Sha256::new();
        ch.update(&buf[..n]);
        whole.update(&buf[..n]);
        chunks.push(ChunkDesc {
            offset,
            length: n as u64,
            sha256: ch.finalize().to_vec(),
        });
        offset += n as u64;
    }
    let mut rng = rand::rngs::OsRng;
    use rand::RngCore;
    let mut tid = [0u8; 32];
    rng.fill_bytes(&mut tid);
    let transfer_id = hex::encode(tid);

    let entry = FileEntry {
        rel_path: rel.to_string(),
        size,
        sha256: whole.finalize().to_vec(),
        chunks,
    };
    let files = vec![entry];
    let sig = id.sign(&signable_bytes(&transfer_id, &files));
    Ok(Manifest {
        version: mtdss_proto::MANIFEST_VERSION,
        transfer_id,
        files,
        sender_signature: sig.to_bytes().to_vec(),
    })
}

fn read_full(f: &mut std::fs::File, buf: &mut [u8]) -> Result<usize> {
    let mut done = 0;
    while done < buf.len() {
        let n = f.read(&mut buf[done..])?;
        if n == 0 { break; }
        done += n;
    }
    Ok(done)
}

pub fn verify(man: &Manifest, sender: &ed25519_dalek::VerifyingKey) -> Result<Vec<FileEntry>> {
    use ed25519_dalek::Verifier;
    anyhow::ensure!(man.version == mtdss_proto::MANIFEST_VERSION, "unsupported manifest version");
    anyhow::ensure!(!man.files.is_empty(), "empty manifest");
    anyhow::ensure!(man.files.len() == 1, "M1 supports exactly one file");
    for f in &man.files {
        anyhow::ensure!(validate_rel_path(&f.rel_path), "illegal rel path: {}", f.rel_path);
        // 块描述一致性：offset/length 首尾相接、总和 == size
        let mut expect_off: u64 = 0;
        for c in &f.chunks {
            anyhow::ensure!(c.offset == expect_off, "chunk offset gap");
            anyhow::ensure!(c.length > 0 && c.length as usize <= CHUNK_SIZE, "chunk length bad");
            expect_off += c.length;
        }
        anyhow::ensure!(expect_off == f.size, "chunk total != size");
        anyhow::ensure!(f.sha256.len() == 32 && c_len32(&f.chunks), "hash length bad");
    }
    let sig = ed25519_dalek::Signature::from_slice(&man.sender_signature)
        .map_err(|_| anyhow!("bad signature encoding"))?;
    sender
        .verify(&signable_bytes(&man.transfer_id, &man.files), &sig)
        .map_err(|_| anyhow!("signature mismatch"))?;
    Ok(man.files.clone())
}

fn c_len32(chunks: &[mtdss_proto::manifest::ChunkDesc]) -> bool {
    chunks.iter().all(|c| c.sha256.len() == 32)
}
```

```rust
use crate::identity::DeviceIdentity;
use crate::protocol::manifest::{self, Manifest};
use anyhow::{anyhow, Context, Result};
use futures_util::AsyncWriteExt;
use mtdss_proto::manifest::FileEntry;
use prost::Message as _;

use std::path::{Path, PathBuf};

pub use crate::protocol::manifest::CHUNK_SIZE;

pub struct SendReport { pub bytes_sent: u64 }

pub fn free_bytes_at(path: &Path) -> u64 {
    fs2::available_space(path).map(|v| v as u64).unwrap_or(u64::MAX)
}

pub fn reject_for_space(needed: u64, available: u64) -> bool {
    needed > available
}

pub async fn send_file(
    conn: &Connection,
    path: &Path,
    rel: &str,
    id: &DeviceIdentity,
    progress: &dyn Fn(u64, u64),
) -> Result<SendReport> {
    let man = manifest::build_single(path, rel, id)?;
    let total: u64 = man.files[0].size;

    // 1) control 流：发 manifest
    let (mut ctl_tx, mut ctl_rx) = conn.open_bi().await?;
    let man_bytes = man.encode_to_vec();
    ctl_tx.write_all(&(man_bytes.len() as u32).to_be_bytes()).await?;
    ctl_tx.write_all(&man_bytes).await?;

    // 2) 等判决
    let mut verdict = [0u8; 1];
    read_exact(&mut ctl_rx, &mut verdict).await?;
    match verdict[0] {
        1 => {}
        0 => {
            let mut len = [0u8; 4];
            read_exact(&mut ctl_rx, &mut len).await?;
            let mut reason = vec![0u8; u32::from_be_bytes(len) as usize];
            read_exact(&mut ctl_rx, &mut reason).await?;
            return Err(anyhow!("rejected: {}", String::from_utf8_lossy(&reason)));
        }
        v => return Err(anyhow!("bad verdict {v}")),
    }

    // 3) 每块一条 uni 流
    let mut file = tokio::fs::File::open(path).await?;
    use tokio::io::AsyncReadExt;
    let mut buf = vec![0u8; CHUNK_SIZE];
    let mut sent: u64 = 0;
    for (idx, chunk) in man.files[0].chunks.iter().enumerate() {
        let mut remain = chunk.length as usize;
        let mut s: Vec<u8> = Vec::with_capacity(CHUNK_SIZE);
        while remain > 0 {
            let want = remain.min(CHUNK_SIZE);
            let n = file.read(&mut buf[..want]).await?;
            anyhow::ensure!(n > 0, "file truncated while sending");
            s.extend_from_slice(&buf[..n]);
            remain -= n;
        }
        let mut uni = conn.open_uni().await?;
        uni.write_all(&(idx as u64).to_be_bytes()).await?;
        uni.write_all(&chunk.length.to_be_bytes()).await?;
        uni.write_all(&s).await?;
        uni.finish().await?;
        sent += chunk.length;
        progress(sent, total);
    }

    // 4) 完成标记 + 等最终确认
    ctl_tx.write_all(&[0xFF]).await?;
    let mut ack = [0u8; 1];
    read_exact(&mut ctl_rx, &mut ack).await?;
    anyhow::ensure!(ack[0] == 0x01, "final integrity check failed at receiver");
    Ok(SendReport { bytes_sent: sent })
}

pub async fn recv_files(conn: &Connection, out_dir: &Path, _me: &DeviceIdentity)
    -> Result<Vec<PathBuf>>
{
    let (mut ctl_tx, mut ctl_rx) = conn.accept_bi().await?;

    // 1) 读 manifest
    let mut len = [0u8; 4];
    read_exact(&mut ctl_rx, &mut len).await?;
    let mut man_bytes = vec![0u8; u32::from_be_bytes(len) as usize];
    read_exact(&mut ctl_rx, &mut man_bytes).await?;
    let man = Manifest::decode(man_bytes.as_slice())?;

    // 对端身份：用 QUIC 客户端证书恢复公钥并验签 manifest
    let peer_pk = peer_verifying_key(conn)?;
    let files = manifest::verify(&man, &peer_pk)?;

    // 2) 磁盘预检 + 接受
    let total: u64 = files.iter().map(|f| f.size).sum();
    if reject_for_space(total, free_bytes_at(out_dir)) {
        reply_reject(&mut ctl_tx, "insufficient disk space").await?;
        return Err(anyhow!("insufficient disk space"));
    }
    ctl_tx.write_all(&[1u8]).await?;

    // 3) 接收块（每块独立 uni 流，乱序到达）
    let entry = &files[0];
    let part_path = out_dir.join(format!("{}.mtdss-part", man.transfer_id));
    let mut part = tokio::fs::File::create(&part_path).await?;
    let mut got: BTreeMap<u64, Vec<u8>> = BTreeMap::new();
    let expected: std::collections::HashSet<u64> =
        entry.chunks.iter().map(|c| c.offset).collect();
    let mut whole = Sha256::new();

    let mut tasks = Vec::new();
    // 单任务顺序 accept uni 流，收满即止（M1 不做并行加速）
    while got.len() < expected.len() {
        let uni = conn.accept_uni().await?;
        let (idx, data) = read_chunk(uni).await?;
        got.insert(idx, data);
    }
    for (_, data) in &got {
        part.write_all(data).await?;
        whole.update(data);
    }
    // 逐块校验
    for c in &entry.chunks {
        let d = got.get(&c.offset).context("missing chunk")?;
        let mut h = Sha256::new();
        h.update(d);
        anyhow::ensure!(h.finalize().to_vec() == c.sha256, "chunk hash mismatch at offset {}", c.offset);
    }
    anyhow::ensure!(whole.finalize().to_vec() == entry.sha256, "whole-file hash mismatch");

    // 4) 原子落盘（冲突改名）
    let final_path = unique_target(out_dir, &entry.rel_path)?;
    tokio::fs::rename(&part_path, &final_path).await?;

    // 5) 等发送方完成标记，回最终确认
    let mut done = [0u8; 1];
    read_exact(&mut ctl_rx, &mut done).await?;
    anyhow::ensure!(done[0] == 0xFF, "sender completion marker missing");
    ctl_tx.write_all(&[0x01]).await?;
    Ok(vec![final_path])
}

fn peer_verifying_key(conn: &Connection) -> Result<ed25519_dalek::VerifyingKey> {
    let certs = conn.peer_identity()
        .and_then(|i| i.downcast::<Vec<rustls::pki_types::CertificateDer>>().ok())
        .ok_or_else(|| anyhow!("no peer cert"))?;
    let first = certs.first().context("empty peer chain")?;
    let (_, parsed) = x509_parser::parse_x509_certificate(first.as_ref())?;
    let raw = parsed.public_key().raw;
    anyhow::ensure!(raw.len() == 44 && raw[..12] == crate::identity::ED25519_SPKI_PREFIX,
        "peer cert not ed25519-device");
    let mut pk = [0u8; 32];
    pk.copy_from_slice(&raw[12..]);
    Ok(ed25519_dalek::VerifyingKey::from_bytes(&pk)?)
}

fn unique_target(out_dir: &Path, rel: &str) -> Result<PathBuf> {
    let rel = PathBuf::from(rel.replace('/', std::path::MAIN_SEPARATOR_STR));
    let target = out_dir.join(&rel);
    if let Some(parent) = target.parent() { std::fs::create_dir_all(parent)?; }
    if !target.exists() { return Ok(target); }
    let stem = target.file_stem().and_then(|s| s.to_str()).unwrap_or("file").to_string();
    let ext = target.extension().and_then(|e| e.to_str()).map(|e| format!(".{e}")).unwrap_or_default();
    for n in 1..u32::MAX {
        let cand = target.with_file_name(format!("{stem} ({n}){ext}"));
        if !cand.exists() { return Ok(cand); }
    }
    Err(anyhow!("cannot find unique name"))
}

async fn read_chunk(mut uni: RecvStream) -> Result<(u64, Vec<u8>)> {
    let mut idx = [0u8; 8];
    read_exact_rs(&mut uni, &mut idx).await?;
    let mut len = [0u8; 8];
    read_exact_rs(&mut uni, &mut len).await?;
    let len = u64::from_be_bytes(len) as usize;
    anyhow::ensure!(len <= CHUNK_SIZE, "oversized chunk frame");
    let mut data = vec![0u8; len];
    read_exact_rs(&mut uni, &mut data).await?;
    Ok((u64::from_be_bytes(idx), data))
}

async fn reply_reject(ctl: &mut SendStream, reason: &str) -> Result<()> {
    ctl.write_all(&[0u8]).await?;
    ctl.write_all(&(reason.len() as u32).to_be_bytes()).await?;
    ctl.write_all(reason.as_bytes()).await?;
    Ok(())
}

async fn read_exact(s: &mut quinn::RecvStream, buf: &mut [u8]) -> Result<()> {
    s.read_exact(buf).await.map_err(|e| anyhow!("stream closed: {e}"))
}
async fn read_exact_rs(s: &mut RecvStream, buf: &mut [u8]) -> Result<()> {
    read_exact(s, buf).await
}
```

```rust
#[derive(Serialize, Deserialize, Default)]
pub struct PeersCache {
    pub peers: HashMap<String, String>, // device_id -> pubkey hex
}

impl PeersCache {
    pub fn load(path: &Path) -> Result<Self> {
        if !path.exists() { return Ok(Self::default()); }
        Ok(serde_json::from_str(&std::fs::read_to_string(path)?)?)
    }
    pub fn save(&self, path: &Path) -> Result<()> {
        std::fs::write(path, serde_json::to_string_pretty(self)?)?;
        Ok(())
    }
    /// TOFU：首次记录，之后必须一致
    pub fn expected_peer(&mut self, device_id: &str, pk: &ed25519_dalek::VerifyingKey) -> Result<()> {
        let hexk = hex::encode(pk.as_bytes());
        match self.peers.get(device_id) {
            None => { self.peers.insert(device_id.into(), hexk); Ok(()) }
            Some(prev) if *prev == hexk => Ok(()),
            Some(prev) => Err(anyhow!(
                "SECURITY: pubkey for {device_id} changed ({prev} -> {hexk}); possible MITM. Refusing.")),
        }
    }
}
```

```rust
pub async fn run_send(session: &Session, file: &Path, to_device: &str, out_report: &dyn Fn(&str))
    -> Result<()>
{
    let me = load_identity()?;
    anyhow::ensure!(me.device_id == session.device_id, "session device mismatch");

    // 对端公钥（服务器）+ TOFU 校验
    let devices = fetch_devices(session).await?;
    let peer = devices.iter()
        .find(|d| d["device_id"].as_str() == Some(to_device))
        .ok_or_else(|| anyhow!("device {to_device} not in account"))?;
    let peer_pk_hex = peer["pubkey"].as_str().context("peer pubkey missing")?;
    let peer_pk = ed25519_dalek::VerifyingKey::from_bytes(
        &hex::decode(peer_pk_hex)?[..].try_into().map_err(|_| anyhow!("bad pubkey"))?)?;

    let mut peers_path = crate::session::mtdss_home().join("peers.json");
    let mut cache = PeersCache::load(&peers_path)?;
    cache.expected_peer(to_device, &peer_pk)?;
    cache.save(&peers_path)?;

    // 信令通道
    let ws_url = format!("{}/ws", session.server.replace("http", "ws"));
    let (client, mut ev) = SignalingClient::connect(&ws_url, &session.jwt, &me.device_id).await?;

    let session_id = rand_bytes_16();
    let offer = seal(&me, &peer_pk, &SignalBody::ConnectRequest { session_id: session_id.clone() });
    client.relay(to_device, &offer).await?;

    // 等 ConnectAccept（E2E）
    let accept = wait_body(&mut ev, to_device, &me, |b| matches!(
        b, SignalBody::ConnectAccept { session_id: s } if *s == session_id)).await?;

    // 收对端 Candidates（内含对端 QUIC 监听地址）
    let cands = match wait_body(&mut ev, to_device, &me, |b| matches!(
        b, SignalBody::Candidates { session_id: s, .. } if *s == session_id).await? {
        SignalBody::Candidates { addrs, .. } => addrs,
        _ => unreachable!(),
    };
    let _ = accept;

    // 逐候选连接
    let ep_a = ep::make_endpoint("0.0.0.0:0".parse().unwrap())?;
    let mut last_err = None;
    let mut conn = None;
    for addr in &cands {
        let Ok(sa) = addr.parse::<SocketAddr>() else { continue };
        match tokio::time::timeout(CONNECT_TIMEOUT,
            ep::connect_pinned(&ep_a, sa, &peer_pk, &me)).await {
            Ok(Ok(c)) => { conn = Some(c); break; }
            Ok(Err(e)) => last_err = Some(e),
            Err(_) => last_err = Some(anyhow!("connect timeout to {addr}")),
        }
    }
    let conn = conn.ok_or_else(|| last_err.unwrap_or_else(|| anyhow!("no candidates")))?;

    // 发送
    let rel = file.file_name().unwrap().to_string_lossy().to_string();
    let path = file.to_path_buf();
    let c2 = conn.clone();
    let report = tokio::spawn(async move {
        transfer::send_file(&c2, &path, &rel, &me, &|done, total| {
            eprintln!("\rprogress {done}/{total} bytes");
        })
    }).await??;
    out_report(&format!("sent {} bytes", report.bytes_sent));
    Ok(())
}

pub async fn run_recv(session: &Session, out_dir: &Path) -> Result<PathBuf> {
    let me = load_identity()?;
    anyhow::ensure!(me.device_id == session.device_id, "session device mismatch");
    let ws_url = format!("{}/ws", session.server.replace("http", "ws"));
    let (client, mut ev) = SignalingClient::connect(&ws_url, &session.jwt, &me.device_id).await?;

    loop {
        // 等一个 ConnectRequest
        let (from_device, body) = loop {
            match ev.recv().await.context("signaling closed")? {
                ClientEvent::Relayed { from, payload } => {
                    // 需要 from 的公钥来验签：向服务器查
                    let devices = fetch_devices(session).await?;
                    let pk = devices.iter()
                        .find(|d| d["device_id"].as_str() == Some(from.as_str()))
                        .and_then(|d| d["pubkey"].as_str())
                        .context("sender pubkey missing")?;
                    let pk_bytes: [u8; 32] = hex::decode(pk)?[..].try_into().map_err(|_| anyhow!("bad pk"))?;
                    let pk = ed25519_dalek::VerifyingKey::from_bytes(&pk_bytes)?;
                    let body = open(&payload, &me, &pk)?;
                    break (from, body);
                }
                ClientEvent::Presence { .. } => continue,
                ClientEvent::Error { code, message } => return Err(anyhow!("signaling error {code}: {message}")),
                ClientEvent::Closed => return Err(anyhow!("signaling closed")),
            }
        };
        let session_id = match body {
            SignalBody::ConnectRequest { session_id } => session_id,
            _ => continue,
        };

        // 对端公钥 + TOFU
        let devices = fetch_devices(session).await?;
        let pk_hex = devices.iter()
            .find(|d| d["device_id"].as_str() == Some(from_device.as_str()))
            .and_then(|d| d["pubkey"].as_str()).context("sender pubkey missing")?.to_string();
        let pk_bytes: [u8; 32] = hex::decode(&pk_hex)?[..].try_into().map_err(|_| anyhow!("bad pk"))?;
        let peer_pk = ed25519_dalek::VerifyingKey::from_bytes(&pk_bytes)?;
        let mut peers_path = crate::session::mtdss_home().join("peers.json");
        let mut cache = PeersCache::load(&peers_path)?;
        cache.expected_peer(&from_device, &peer_pk)?;
        cache.save(&peers_path)?;

        // 接受 + 开 QUIC 服务器端点 + 发 Candidates
        let mut allowed: HashMap<String, ed25519_dalek::VerifyingKey> = HashMap::new();
        allowed.insert(from_device.clone(), peer_pk);
        let ep_b = ep::make_server_endpoint("0.0.0.0:0".parse().unwrap(), &me, &allowed)?;
        let port = ep_b.local_addr()?.port();
        let cands = local_candidates(port);
        client.relay(&from_device, &seal(&me, &peer_pk,
            &SignalBody::ConnectAccept { session_id: session_id.clone() })).await?;
        client.relay(&from_device, &seal(&me, &peer_pk,
            &SignalBody::Candidates { session_id, addrs: cands })).await?;

        let ep_clone = ep_b;
        let (conn, _dev) = ep::accept_pinned(&ep_clone, &allowed).await?;
        let paths = transfer::recv_files(&conn, out_dir, &me).await?;
        return Ok(paths[0].clone());
    }
}

async fn wait_body(
    ev: &mut tokio::sync::mpsc::Receiver<ClientEvent>,
    from: &str,
    me: &DeviceIdentity,
    pred: impl Fn(&SignalBody) -> bool,
) -> Result<SignalBody> {
    let deadline = tokio::time::timeout(SIGNAL_TIMEOUT, async {
        loop {
            match ev.recv().await.context("signaling closed")? {
                ClientEvent::Relayed { from: f, payload } if f == from => {
                    // 验签需要发送方公钥 —— 调用方保证 from 可信后传入
                    // 简化：由调用方包装（见 run_send 中显式 open 调用替换本函数）
                    todo!("replaced below")
                }
                _ => continue,
            }
        }
    }).await;
    deadline.map_err(|_| anyhow!("signaling wait timeout"))?
}
```
